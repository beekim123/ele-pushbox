# 参考游戏笔记（改版轮 V1）

> 用途：v0.3 每一条操作、引导、界面、美术的做法都要能指回这里的某款游戏。只记“借什么”，不复述游戏本身。
> 规则：同一件事有多个参考时，优先选玩家最可能玩过的那一款。

## 1. 操作

| 要做的事 | 参考 | 借的做法 | 用在 |
|---|---|---|---|
| 网格里走、推 | 经典推箱子、Baba Is You、Snakebird | 只用方向键；一次按键 = 一步；没有“确认” | 推箱 |
| 登一格台阶 | Catherine | 走向一格高的台阶自动登上，两格高登不上 | 推箱 |
| 挖和放 | Minecraft、Terraria | 鼠标指向目标：左键挖、右键放；只在够得着的范围内生效，指针所在格高亮 | 推箱 |
| 拖着挖土 | Where's My Water? | 按住拖动，经过的泥土消失；岩石挖不动；水立刻顺着新开的道流 | 塔防清晨 |
| 预览后果 | Into the Breach | 鼠标悬停就显示这一下的全部后果（推到哪、谁受伤）；点下去直接执行，不需要第二次确认 | 推箱挖 / 倒 / 炸 |
| 撤销、重开 | Baba Is You、Patrick's Parabox | Z 撤销（可连按、无上限），R 重开，都不弹确认；撤销代替了“三思后行”的确认框 | 推箱 |
| 消耗品 | 植物大战僵尸、Bloons TD | 从屏幕边的图标拖到地图上；拖动时显示作用范围，松手生效，拖回原处取消 | 推箱炸药、塔防炸药 |
| 和机关互动 | Spelunky（在门前按 ↑） | 站在机关前按 ↑；鼠标直接点机关也行 | 推箱拉杆 |
| 造塔 | Kingdom Rush | 地图上画出空塔位；点它，周围弹出一圈塔图标和价格；买不起的变灰；点已造的塔弹出升级 / 卖掉 | 塔防 |
| 开始一波 | Kingdom Rush | 敌人入口处一个闪动的按钮，点它出怪；按钮上显示下一波的敌人图标 | 塔防 |
| 倍速、暂停 | Kingdom Rush、Bloons TD | 屏幕角落两个小图标按钮；空格暂停 | 塔防 |

**不再用的做法**：先选工具再操作（Lemmings 式工具栏，状态多、易忘当前模式）；同一个键在不同情况下做不同的事；按两次确认。

## 2. 引导

| 参考 | 借的做法 |
|---|---|
| Where's My Water? | 前十关每关只引入一样东西；第一关画一只手在泥土上划过，玩家照做一次提示就消失 |
| 植物大战僵尸 | 每关解锁一样新东西，开局一张卡片介绍（图 + 一句话）；第一关只有一种植物、一条路 |
| Kingdom Rush | 第一关只有箭头指着塔位和出怪按钮；新敌人第一次出现时弹一张小卡，可以关掉 |
| Baba Is You、Snakebird | 不写教程文字，用关卡本身教：第一关只能做对一件事 |
| Celeste | 按键提示直接画在场景里（墙上、地上），离开那段就看不到 |

共同点：**做一次就学会，提示在玩家做对后马上消失；一屏最多一句话；不靠说明书式的长文字。**

## 3. 界面

| 参考 | 借的做法 |
|---|---|
| Kingdom Rush | 左上角一条：生命、金币、波数，都是图标 + 数字；其余一切在地图上 |
| Baba Is You、Patrick's Parabox | 关卡里完全没有界面元素；Esc 菜单里才有选关、重开、设置 |
| Dome Keeper | 横版剖面 + 两阶段（挖矿 / 守波）；阶段切换靠画面本身（天色、音乐、敌人倒计时），不靠面板 |
| Kingdom Two Crowns | 金币就是画面里的实物，不是数字面板 |

规则：**能画在地图上的不放进面板；能用图标的不用文字；玩家做决定用不到的数不显示。**

## 4. 美术

| 参考 | 借的做法 |
|---|---|
| Noita | 每个像素都是模拟材料；靠材料颜色的细微抖动、液体表面高光、发光材料（火、熔岩）的光晕让画面“活”起来 |
| Where's My Water? | 剖面泥土有明显的地层纹理和挖开后的深色边缘；水是饱和的亮蓝，和土的暖色对比强 |
| Dome Keeper、SteamWorld Dig | 地下剖面：越深越暗；背景有一层远景（天空 / 洞壁）让剖面有纵深 |
| Terraria | 方块边缘有 1 像素的亮边 / 暗边，让地形轮廓清楚 |
| Kingdom Rush | 塔、敌人轮廓粗、剪影好认；每种敌人一个主色 |

## 5. 字体（已查证许可）

- **缝合像素字体 Fusion Pixel Font**（TakWolf）：泛中日韩像素字体，12px，SIL OFL 1.1，可商用。方舟像素字体（Ark Pixel，OFL 1.1）字还不全，作者建议 10px、12px 先用缝合像素。
- 来源：<https://github.com/TakWolf/fusion-pixel-font>、<https://github.com/TakWolf/ark-pixel-font>

## 6. Where's My Water? 的补充细节（已查证）

- 目标是把足够的水引到出水口；水越多分越高。
- 泥土可挖、岩石不可挖；有颜色区分的开关、管道、转换器；还有会慢慢吃土的绿色液体、会干成土的泥浆。
- 前几关每关只引入一个概念，之后再组合。
- 来源：<https://en.wikipedia.org/wiki/Where's_My_Water>、<https://tropedia.fandom.com/wiki/Where's_My_Water>

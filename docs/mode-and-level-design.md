## 0. 方案审核结论与底层物理防坑修正（保留全部技术细节）

对照《项目目标与需求记录》（G01–G06）、《ele-base-cpp 能力清单》（v1.2.0）及现有 GDScript 实现，本设计方案修正了 6 处关键物理与规则断层，确保 GPT 开发时一次跑通：

| 审核发现问题 | 根因分析（对照 SDK 与现有代码） | 定稿修正方案 |
| :--- | :--- | :--- |
| **1. 缺失 `G06` 刚体核心目标** | `project-goals.md` 明确要求利用 SDK 刚体特性（`G06`），但 Box2D 刚体位置连续、不参与反应且快照不保证位级一致，不能直接当网格推箱。 | 设计 **M12「重锤崩落（瞬态刚体）」**：爆破或酸蚀支撑点后，在结算期调用 `create_body_from_rect` 生成 Box2D 刚体演出倾倒、翻滚与撞击，**静止当轮立即调用 `destroy_body` 写回元胞网格**，回合末快照零残留刚体，100% 兼容撤销与预演。 |
| **2. M10 水火反应「1 像素结壳自锁」与产物冲突** | `ele.reactions/1` 仅检查 4 邻域且每关固定一张反应表。若水浇在熔岩顶面生成 `static` 裂岩或低密度沙，交界面第 1 行（16 cell）生成后即隔绝上下流体，反应停滞在 16–32 cell，远低于 `board.gd` 的 `128` cell 分类阈值。 | 统一反应为 `water + lava -> pumice + pumice`，并采用**密度倒置对流**：`water(30) < lava(50) < pumice(90, powder)`。生成的浮石沙自动沉入熔岩池底，把未反应熔岩顶向表面直至整格 256 cell 完全反应为 `SAND` 类。 |
| **3. M9 酸液侧面蚀墙触发「悬空残留不崩落」** | `cracked_rock` 为 `static` 材料。若酸液沿平地从侧面接触裂岩墙，仅能腐蚀底部 2–3 行（约 48 cell），上方 ~208 cell 悬空不落且 $\ge 128$（不触发 `crumble_below`），墙体永远打不通。 | 反应产物设为 `acid + cracked_rock -> fume(短寿命气体) + empty`；明确关卡几何约束：**受蚀裂岩必须采用「顶面漫灌」或「满高蓄酸侧槽」结构**，借重力蚀穿 $\ge 129$ cell 后由 `resolve_round()` 自动整格崩落。 |
| **4. 连通器倒沙堵塞拐角与浮箱高度差误判** | `board.gd` 中 `_water_top` 要求箱底到液面保持 4 连通 `"WATER"` 格，且木箱停在 `water_top - 1`。若 U 形管无沉沙囊，倒沙会把底部拐角变成 `"SAND"` 切断水路；若木箱浮在岸面层，结冰后会挡住岸面推路。 | **T03/C04/C05** 强制要求 U 形管投沙臂底部增设低于水平连通管的**沉沙囊（Sump Pocket）**；区分**「推箱上岸（液面齐岸）」与「浮桥垫脚（液面低 1 格）」**的液位高度差规范，并修正 **C11** 的冰面推箱顺序。 |
| **5. T01 地图行宽非法且违背「箱子不可登台阶」** | 原 T01 第 5 行有 11 个字符（其余行 10 字符），会触发 `level_loader.gd` `"地图每行必须等宽"` 报错；且 `step_up: 1` 仅对人物生效，箱子无法被推上 1 格台阶。 | 修正 T01 为标准 `10×6` 等宽地图，并将地形与 `entities` 分离；流程改为“人物登 1 格台阶 + 爬梯上高台 → 将箱子推落至下层平地 → 推入目标 `T`”。 |
| **6. C13 误将沙袋 `bag` 当作先进后出（LIFO）栈** | `board.gd` 中 `bag` 为 `Dictionary`，`POUR_` 严格按 `rules.pour.order` 固定列表顺序倾倒，不记录入袋先后顺序。 | 将 **C13《双色沙漏》** 设计为基于 `pour.order: ["pumice", "sand"]` 的**「轻浮石在上、重黄沙在下」固定优先级倾倒博弈**，无需改动存档结构即可实现取沙与倾倒时序谜题。 |

## 1. 三大阶段推进总纲与美术代码化铁律

### 1.1 三大阶段路线
1. **第一阶段（当前优先交付 GPT 执行）**：
   - **美术全改为纯代码生成**：彻底去掉 `.png` 贴图文件依赖，所有角色、物件、图标与 UI 面板在 GDScript 启动时由代码动态生成内存 `ImageTexture`，地形全由 `world.gdshader` 纯代码绘制。
   - **主界面大厅 UI（Lobby UI）+ 精简教学模式（`T01–T04` 共 4 关）**：做好游戏启动大厅、三模式选择卡片与选关面板，并用 4 个简单直观的关卡快速演示并覆盖全部核心操作。
2. **第二阶段（闯关模式：按特性做增量解谜 + 接入更多 SDK 特性 + 设计 SDK 新特性）**：
   - 围绕不同特性分章节制作闯关模式增量关卡（`C01–C15` 及后续扩展章节），逐步把 SDK 现有的沉水铁箱、酸液蚀岩、水火化沙、急冻冰桥、热力学燃烧、电路火花、瞬态刚体崩落等特性加进来。
   - 同步设计当前 SDK 尚不具备的新特性（见第 5 节），输出规格交由用户去 SDK 仓库实现扩展后再接入关卡。
3. **第三阶段（地狱挑战模式：全特性大熔炉）**：
   - 将闯关模式中的所有特性（含新增 SDK 扩展特性）全部糅合，在 `640×384`（`2×2` 房间连通）大地图上结合动态陷阱与可利用怪物，打造起步即地狱难度的综合挑战关卡（`CH01–CH03`）。

### 1.2 纯代码美术架构规范
- **GDScript 内存贴图生成器（`pushbox/scripts/ui/pixel_style.gd` / `procedural_art.gd`）**：
  - 内置 ENDESGA 32 调色板与字符像素矩阵/绘制函数，在 `Style.warm_assets()` 和 `Style.texture(name)` 中直接通过 `Image.create()` + `set_pixel()` 生成 `ImageTexture` 并缓存。
  - 保持所有 `texture(name)` 名称、尺寸（`16×16` 等）、锚点及不透明像素分布与原图一致，确保 GPU 单次 `draw_texture` 零性能损耗，且现有 14+1 个测试脚本（含 `tests/bugfix.gd` 的人物朝左逐像素镜像测试）100% 通过。
- **纯 Shader 地形渲染（`pushbox/scripts/render/world.gdshader`）**：
  - 将 `bedrock`（16×16 砌块纹理与受光边）、`cracked_rock`（暖褐岩体与深色裂纹）及后续新增的 `acid`、`fume`、`lava`、`pumice`、`ice` 全部在 `fragment()` 中用确定性坐标哈希与数学函数计算，不再加载外部纹理图片。

## 3. 机制体系总表（M1–M12 + 待扩展 SDK 特性）

| 编号 | 机制名称 | 玩家操作 | 物理与离散规则表现（含底层约束） | 所属阶段 |
| :--- | :--- | :--- | :--- | :--- |
| **M1** | 推箱与重力坠落 | `←` `→` 推箱 | 箱子仅在前方为 `OPEN` 或 `WATER` 时水平推 1 格（无连推、无拉箱、**箱子不可登台阶**），下方无支撑时直落到底 | 第一阶段（教学） |
| **M2** | 单格登台阶与爬梯 | `←` `→` / `↑` `↓` | 仅**人物**在头顶与目标格上方均 `enterable` 时可斜向上登上 1 格高障碍；沿梯子 `U`/`D` 移动 | 第一阶段（教学） |
| **M3** | 挖沙与倒沙造地形 | 左键挖 / 右键倒 | 挖掘相邻 `SAND` 类格内的 `#loose` 材料存入 `bag`，倾倒后按粉末规则自然坍塌成 45° 坡充当台阶或垫层 | 第一阶段（教学） |
| **M4** | 连通器与木箱浮力 | 拉杆 / 机关放水 | `liquid_pressure` 拉平 4 连通开口液面（误差 $\le 1$ cell）；木箱在连通水体最高开敞液面 `water_top <= box.y` 时上浮，最终停在**水面之上 1 格（`water_top - 1`）** | 第一阶段（教学） |
| **M5** | 倒沙入水排水抬升 | 右键向水道倒沙 | 沙沉入水底**沉沙囊（Sump Pocket）**占据体积，挤高开敞臂水位并保持底部 4 连通 `"WATER"` 路径不断裂，间接抬升远端木箱 | 第一阶段（教学） |
| **M6** | 十字爆破与崩落 | 拖拽炸药松手 | `explode(center, 20, 8000)` 摧毁中心与四邻格 `#breakable` 材料，剩余 `< 128` cell 在 `resolve_round()` 中自动整格清空 | 第一阶段（教学） |
| **M7** | 多条件机关与闸门 | 踩压板 / 扳拉杆 | 支持 `lever`、`plate`、`water`、`count`、`box_at` 组合控制闸门；门格内非空颗粒 `> 16` cell（`crush_max`）时可卡住闸门阻止关闭 | 第一阶段（教学） |
| **M8** | **沉水铁箱** | `←` `→` 推铁箱 | 铁箱（`kind: "iron"`，`floats: false`）入水时通过 `_swap_box` 将水向上置换并直沉水底，可触发水底压板、充当水下桥墩或镇压喷口 | 第二阶段（闯关） |
| **M9** | **酸液蚀岩** | 放酸液 / 倒沙引流 | 酸液（`acid`）自上而下或满槽接触裂岩（`cracked_rock`）时反应生成短寿命烟雾 `fume` 并消除裂岩；蚀穿 $\ge 129$ cell 后整格崩落；酸液不挂 `fluid` 浮力标签 | 第二阶段（闯关） |
| **M10** | **水火化沙（熔岩相变）** | 放水 / 倒沙改道 | 水（`density: 30`）接触熔岩（`density: 50`）反应生成重质**浮石沙 `pumice`（`powder`, `density: 90`, `#loose`）**；浮石沙自动沉底引发熔岩对流直至整格完全化沙，可踩踏或挖入沙袋 | 第二阶段（闯关） |
| **M11** | **急冻冰桥与解冻** | 拉杆 / 压板触发 | 经 `couplers` 求解器（`frost`/`thaw` layer，`stride: 1`）或温控机关将指定区域内的 `water` 与实心 `ice`（`#solid`, `#breakable`）互转，实现“水面托木箱 ↔ 冰面推铁箱” | 第二阶段（闯关） |
| **M12** | **重锤崩落（瞬态刚体）** | 爆破 / 酸蚀支撑点 | 摧毁悬石或配重块下方的 `cracked_rock` 支撑后，由 `create_body_from_rect` 生成 Box2D 刚体演出坠落、翻滚与撞击；**静止当轮调用 `destroy_body` 栅格化写回网格**（落实 `G06`） | 第二阶段（闯关） |
| **M13+** | **热力学燃烧 / 电路火花 / SDK 新扩展特性** | 机关触发 / 环境耦合 | 接入 SDK 现有 `thermal`（导热引燃 `burnable`）、`electric`（电火花点燃气障），以及由用户扩展进 SDK 的新特性（见第 5 节） | 第二阶段中后期 |

## 4. 第一阶段关卡设计：教学模式（Tutorial Mode · T01–T04 极简覆盖）

- **定位**：第一阶段只做 **4 个简单直接的教学关**，3–5 分钟内让玩家学会所有基础操作（M1–M7），不堆砌复杂衍生机制。
- **合规引导约束（对齐 `level_loader.gd`）**：每条 `guide` 的 `text` 严格 $\le 8$ 个汉字，且单选 `keycap`（`UP`/`DOWN`/`LEFT_RIGHT`/`Z_R`）、`mouse`（`left`/`right`）或 `hand`（`hud:bombs -> map`）之一。

### T01：移动与推箱（覆盖 M1 + M2：方向键移动、1 格登台阶、爬梯、推箱入坑、撤销/重开）
- **教学目标**：理解“人物可直接走上 1 格高台阶、2 格高差需爬梯子，而箱子只能平推或推落凹坑”。
- **地形与物件布局（10×6，严格等宽）**：
  ```text
  ##########   图例（Terrain）: # = bedrock, . = empty
  #........#   物件（Entities）:
  #...A....#     player = [1, 4], boxes = [{id:"A", at:[4, 2], kind:"wood"}]
  #..#####.#     ladders = [[2, 2], [2, 3]], targets = [[8, 4]]
  #@.#...#.T#   说明: (1,4)人物先向右登上(2,3)单格台阶(#在(2,4))，再沿(2,3)-(2,2)爬梯上平台
  ##########         将(4,2)的箱子A一路向右推落到(7,4)平地，最后跳下平台把A推入(8,4)目标T
  ```
  *(注：实际 JSON 中 `map` 第 5 行为 `#.#....#.#`，人物、箱子、梯子、目标均定义在 `entities` 中，保证每行严格 10 字符。)*
- **标准解法（8 步）**：`R`（登 1 格台阶到 `2,3`）→ `U`（爬梯到 `2,2`）→ `R` → `R` → `R` → `R`（将 `A` 从 `4,2` 推落至 `7,4`）→ `R`（人物跳落至 `6,4`）→ `R`（将 `A` 推入 `8,4` 目标 `T`）。
- **关联引导（`guides`）**：
  1. `id: "step"`, `keycap: "LEFT_RIGHT"`, `text: "向右登一格台阶"`, `done: {"player_at": [2, 3]}`
  2. `id: "climb"`, `after: "step"`, `keycap: "UP"`, `text: "按上爬梯子"`, `done: {"player_at": [2, 2]}`
  3. `id: "push"`, `after: "climb"`, `keycap: "LEFT_RIGHT"`, `text: "推箱落下高台"`, `done: {"box_at": ["A", [8, 4]]}`

### T02：挖沙与造坡（覆盖 M3：悬停预演、左键挖沙、右键倒沙堆台阶）
- **教学目标**：学会观察鼠标悬停预演，左键点击相邻沙格装入右上角沙袋，右键向相邻格倒沙堆出 45° 沙坡登上 2 格高台。
- **地形结构（10×6）**：
  - 人物左侧 `(1,3)-(1,4)` 有两格黄沙 `s`，右侧 `x=5..8` 是 2 格高的基岩平台（顶面 `y=2`），平台上有箱子 `A (6,2)` 与右侧坑底目标 `T (8,4)`。
- **核心流程**：左键挖沙 `DIG_L` → 走到 2 格高台前 `(4,4)` 右键倒沙 `POUR_R` → 沙子坍塌在 `(4,4)` 形成 `SAND` 垫脚格 → 向右单格登上高台推箱进坑。
- **关联引导**：`mouse: {button: "left"}` `"左键挖左侧黄沙"` (`done: "dug"`) → `mouse: {button: "right"}` `"右键倒沙垫台阶"` (`done: "poured"`)。

### T03：放水与浮箱（覆盖 M4 + M5：拉杆放水、连通器木箱上浮、沉沙囊倒沙抬升液面）
- **教学目标**：学会扳动拉杆开门放水，观察连通器水位拉平托起木箱，并通过向左侧带沉沙囊的水道倒沙把木箱彻底顶出井口。
- **地形结构与几何约束（11×8）**：
  - 开局自带 1 袋沙（`budget.sand_cells = 256`）。
  - 右侧储水池由拉杆 `L1` 控制闸门 `G`；中央 U 形连通器左臂开口在 `(4,4)`，**左臂正下方 `(4,6)` 设有 1 格深沉沙囊（Sump Pocket）**，右臂井内停着木箱 `A`。
- **核心流程**：扳动拉杆 `USE` 打开闸门 → 水涌入连通器将木箱 `A` 托升至距井口差 1 格处 → 走到左臂井口旁右键倒沙 `POUR_R` → 沙沉入底部沉沙囊 `(4,6)` 置换出 1 格水（水平连通管保持 100% `"WATER"` 4 连通）→ 右臂水位再涨 1 格将木箱 `A` 顶出井口 → 推箱入目标。

### T04：机关与爆破（覆盖 M6 + M7：推箱踩压板、踩受阻箱翻越、拖拽炸药十字爆破）
- **教学目标**：学会用箱子压住压板开门、踩着受阻推不动的箱子翻越障碍，以及从右上角拖拽炸药图标爆破裂岩。
- **地形结构（12×5）**：
  - 前半段用箱子 `A` 压住坑底压板打开闸门；后半段箱子 `B` 右侧紧贴裂岩 `c`，右上角配有 1 枚炸药。
- **核心流程**：推左箱 `A` 入坑踩压板开门 → 踩着被裂岩 `c` 挡住的右箱 `B` 翻到右侧 → 向左拖拽炸药 `BOMB_L` 炸毁裂岩 `c`（剩余 `< 128` cell 自动整格崩落）→ 从右侧把 `B` 往左推入目标。

### 5.4 第二阶段同步设计的「SDK 新扩展特性规格」（由用户去 SDK 补充）
在推进第二阶段闯关模式期间，可进一步接入 SDK 现有的 **`thermal`（导热引燃 `burnable` 木障/引信）** 与 **`electric`（导电火花）**，并由设计侧输出 `docs/sdk-extension-requests.md`，供你在 `ele-base-cpp` 中扩展以下底层新能力：
1. **`EXT-09` 休眠水体无损唤醒命令（`wake_rect`）**：箱子移走或冰块解冻时，无需靠“改空一个水 cell 再改回水”来唤醒休眠水体。
2. **`EXT-03` 排除周期性电路的静止查询（`is_settled`）**：让带持续电源 `power_source` 的 Wireworld 电路不阻塞回合制的 `quiet_ticks` 静止判定，彻底解锁常驻通电机关关卡。
3. **方向性与温度条件反应（Directional & Thermal Reactions）**：支持仅在“上方接触”或特定温度区间触发反应。
4. **持续风场发射器（Wind Emitter）与流体流量传感器（`EXT-06`）**：支持风吹沙流偏转、水流冲击水车发电开门等高阶物理谜题。

## 6. 第三阶段设计：地狱挑战模式（Challenge Mode · 全特性大熔炉）

待第二阶段闯关模式所有特性与 SDK 新扩展就绪后启动：
1. **起步即地狱难度**：不设单机制热身，从 `CH01` 起即把闯关模式中的所有特性（沉水铁箱、酸液蚀岩、熔岩化沙、急冻冰桥、燃烧电路、瞬态刚体崩落及新 SDK 扩展特性）全部糅合。
2. **单实例 `640×384` 大地图 + 房间级镜头（Unified Megamap with Room Camera）**：
   - 采用 `sdk-capability-map.md` 已实测验证的 **`640×384` 像素（10×6 个 `64×64` chunk，对应 `40×24` 格 = 2×2 个标准 `20×12` 房间）** 单一 `EleWorld` 实例，让水、酸液、熔岩、连通器压力与刚体滚落**天然跨房间边界连续模拟**。
   - 支持**「当前 `20×12` 房间精细操作视口」**与 **`Tab` 键「`40×24` 全图总览视口」**一键切换；跨过房间边界且满足阶段条件时，自动更新**房间级检查点（Checkpoint Snapshot）**。
3. **回合同步环境威胁与可利用怪物/陷阱**：
   - **定量间歇泉 / 滴酸口（Periodic Spawner）**：每 $N$ 回合向指定格注入定量水、酸液或熔岩，既是限时淹没威胁，也是定量流体来源。
   - **巡逻石像鬼 / 滚石机关（Grid Patrol & Rigid Hazard）**：按确定性网格规则移动，玩家可引诱石像鬼替自己踩住远端死路压板、用酸液将其溶解，或将其推入熔岩坑反应化为垫脚石。
4. **首批地狱挑战关卡原型（CH01–CH03）**：
   - **CH01《地下引水渠》（40×24，2×2 房间）**：左上房（蓄水与刚体吊桥）+ 右上房（间歇酸泉与裂岩迷宫）+ 左下房（熔岩炉与唯一沙源）+ 右下房（三箱高低靶终点）。需在右上房酸液淹死左下房沙源前，炸断左上房吊桥重锤（**M12** 刚体坠落堵住左路泄洪口），将酸液改道引入右下房蚀开铁箱牢笼。
   - **CH02《熔炉之心》（40×24，竖向深井双塔）**：从顶层护送 1 只木箱与 1 只铁箱穿过三层熔岩槽、冷冻机关与巡逻石像鬼；引诱石像鬼踩住中层冷冻压板将瀑布冻成冰柱，再借冰柱把铁箱滑送到对面镇压底部熔岩喷口。
   - **CH03《阿基米德的审判》（40×24，四臂跨房巨型连通器）**：贯穿四个房间的巨型连通水网，包含水、酸液、熔岩三种流体与两处冷冻闸门，精确计算每次投沙、放水、结冰与解冻对四个房间液面的连锁影响。

## 1. 现有实现五大「AI 味与不美观」病灶诊断（基于当前代码逐行排查）

通过检查当前仓库中的 `theme_*.gd`、`ambient_art.gd`、`biome_gimmicks_art.gd`、`lobby_view.gd` 与 `biome_showcase_view.gd`，定位出导致画面简陋、充满“程序拼凑 AI 味”的 **5 个具体代码根因**：

| 序号 | 视觉问题表象 | 当前代码根因定位 | 彻底整改方向 |
| :--- | :--- | :--- | :--- |
| **1** | **背景全是死板的方块拼接，一眼看穿是 `for` 循环画的矩形（重度 AI 味）** | `theme_forest.gd`、`theme_ruins.gd`、`theme_sky_island.gd` 全部使用 `for x in range(-32, size.x, 64): Ops.rect(...)` 在固定网格上画长方形色块（比如森林树干就是两条垂直长方形色带，天空岛就是 4 条生硬横色带 + 3 个叠放长方形当云朵）。 | **禁用规则大矩形充当自然景物**：改用「像素轮廓模板（Silhouette Stamp）+ 抖动渐变（Bayer Dither）+ 奇偶行交错偏移」，画出有树冠弧度、树根分叉、云朵圆润凸起、远近双层视差的自然像素背景。 |
| **2** | **画面像死水一样完全不动（云不飘、草不摇、没有花和小动物，连灯都不闪了）** | 1. `biome_showcase_view.gd` 甚至没有写 `_process(delta)`，整张预览画面是 0 帧率的死图；<br>2. `ambient_art.gd` 的 `themed_lamp(theme, accent)` 根本没接收 `frame` 参数，`lantern_idle_0` 和 `lantern_idle_1` 拿到的是同一张死图，导致新地图连挂灯都不闪了；<br>3. 没有任何地表植被与小生物层。 | 新增独立的**「动态生态与环境动效层（`ambient_ecology.gd`）」**：实现**天空岛多层视差飘云**、**森林随风摇摆的花草与藤蔓 + 蹦跳小鸟/蝴蝶/青蛙**、**洞穴滴酸/荧光飞蛾**、**遗迹流沙细流/圣甲虫**、**宇宙旋转星尘/巡航小无人机**。 |
| **3** | **独特机关缩成一团糊像素，破坏了 1:1 像素网格** | `biome_gimmicks_art.gd` 画的是 `32×32` 和 `64×48` 的粗糙几何线框，但 `board_view.gd` 第 153 行和 `biome_showcase_view.gd` 第 213 行却用 `Rect2(..., Vector2(16, 16))` **把 `64×48` 的贴图强行压缩进 `16×16` 格子里**，导致像素严重畸变、线条断裂！ | **严格遵守 1:1 原生像素比例**：单格机关统一按 `16×16` 精绘像素矩阵；多格机关（如 `16×32` 漏斗、天平托盘）按真实像素尺寸 `texture.get_size()` 原大绘制，**严禁缩放变形**。 |
| **4** | **UI 页面像简陋的工程调试表格，文字挤爆边框、分辨率还不统一** | 1. `lobby_view.gd` 的 `_draw_campaign()` 在 `320×180` 里硬塞了顶部 6 个 `50×20` 挤成一排的小方框 + 右侧 6 个 `93×28` 文字贴边方框（边距仅 2px，塞满 `"01 ★ 可玩"`、`"1/6 满3通行"` 等说明书式文字）；<br>2. `biome_showcase_view.gd` 擅自改用 `640×360` 坐标系，上下画两条大黑边，导致字体和九宫格面板比大厅缩小一半，风格完全割裂！ | **重构为《Celeste / Kingdom Rush》式画卷选关 UI**：全游戏 UI 统一锁死 `320×180` 逻辑画布；砍掉密密麻麻的表格框，改用**「顶部地图图标徽章条 + 中央大画幅主题微缩景观卡 + 底部 6 枚清爽关卡节点（圆环/星标）」**。 |
| **5** | **地图结构全是“横平竖直火柴盒”，6 张地图长一个样** | 现有展示图与关卡 JSON 全是外圈一圈 `#` 方框、里面几条水平 `#` 横梁（`######...####`），地牢、森林、天空岛的地形骨架完全一样，看不出谁是树洞、谁是浮岛、谁是神庙。 | **按生态地貌彻底重设计地图轮廓**：森林采用“高低错落古树冠与盘根中空树洞”，天空岛采用“无外框四面悬空的阶梯浮岛群”，洞穴采用“钟乳石犬牙交错的斜向溶洞”，遗迹采用“金字塔阶梯斜坡”。 |

## 2. 六大地图「去 AI 味 · 动态生态与小动物/植物/飘云」详细设计

为彻底消除“程序画矩形”的冰冷感，在 `board_view.gd` 与 `biome_showcase_view.gd` 中新增一个轻量级的**纯视觉动态生态渲染器（`pushbox/scripts/render/ambient_ecology.gd`）**。所有小动物、花草摇曳与飘云仅在渲染层根据 `clock` 与关卡固定 `seed` 绘制，**零物理开销、不进 SDK、不影响任何关卡解法哈希**。

### 2.2 森林野花、小动物与天空岛飘云的像素矩阵与绘制规格（可直接落地）

1. **森林草皮上的野花与小动物生成规则（自动附着于裸露草皮格）**：
   - 扫描地图中所有上方为空气（`empty`）的 `bedrock` 格，按确定性哈希 `(tile.x * 37 + tile.y * 13) % 7` 自动在草皮顶面生成生态点缀（不遮挡箱子与人物，当人物或箱子走到该格时小鸟轻巧飞起、花草压弯 1px）：
     - **红白小花 / 金黄雏菊（`flower_sway_0..1`，`8×6`）**：每 `0.6s` 根据 `int(clock * 2 + tile.x) % 2` 花冠左右偏移 1px，呈现微风拂过草甸的律动感。
     - **林间小鸟（`forest_bird_0..3`，`8×8`）**：
       ```text
       # 帧 0（站立张望）      # 帧 1（低头啄食）      # 帧 2（开心小跳 y-1）
       ....zzzz....          ............          ....zzzz....
       ...ziiiiiz..          ....zzzz....          ...ziiiiiz..
       ..ziiitziiz.          ...ziiiiiz..          ..ziiitziiz.
       .ziiiiiikkz.          ..ziiitziiz.          zziiiiiikkz.
       ziiiiiiizz..          .ziiiiiijjz.          .ziiiiiiizz.
       .zzffffzz...          zfffffzzzz..          ..zzffffzz..
       ...z..z.....          ...z..z.....          ..z....z....
       ...z..z.....          ...z..z.....          ............
       ```
     - **翩跹蝴蝶（`butterfly_0..1`，`5×5`）**：在花朵上方 `8..16px` 处按 `Vector2(sin(clock * 2.2 + seed) * 6, cos(clock * 3.5 + seed) * 3)` 扇翅飞舞。

2. **天空岛三层视差飘云与抖动霞光算法（彻底消灭死板色带与静止方片云）**：
   - **天幕 Bayer 抖动过渡**：相邻两层天幕色带交界处（`4px` 宽过渡带），按 `(x + y) % 2 == 0` 交错绘制上下两色像素，呈现纯正复古像素游戏的细腻霞光过渡。
   - **动态飘云层（在 `_draw()` 中实时按 `clock` 偏移绘制）**：
     - 预生成 3 种不同尺寸的圆润蓬松像素云朵精灵（`cloud_far` `24×8`、`cloud_mid` `40×12`、`cloud_near` `56×16`，顶部纯白 `#ffffff` 圆弧凸起、中部 `#c0cbdc`、底边 `#8b9bb4` 阴影），在 `_draw()` 中以 `fposmod(base_x + clock * speed, canvas_width + 64) - 32` 持续平滑横移！

## 3. UI 界面全面美化重构设计（告别简陋后台表格感）

严格对标《Celeste（蔚蓝）》与《Kingdom Rush》的精致像素 UI，遵守 [`docs/v3/ui-art-direction.md`](v3/ui-art-direction.md) 规则，对 **主大厅（Lobby）**、**闯关模式地图池（Campaign Select）** 与 **观察池（Observation Pool）** 进行全面视觉重做：

### 3.1 全局 UI 三条硬性美化准则
1. **统一 `320×180` 逻辑画布**：将 `biome_showcase_view.gd` 从突兀的 `640×360` 改回与全游戏一致的 **`320×180` 原生画布**（对于超宽大地图，支持在 `320×180` 视口内按方向键/鼠标平滑平移镜头或一键切换 `1:1 原生细节 / 缩略全景`），确保全游戏字体大小、像素粗细与九宫格边框 100% 统一！
2. **砍掉拥挤的方框套方框与说明书文字**：按钮与卡片内留足至少 `4–6px` 呼吸内边距；用直观的**像素图标（星标 `★`、金冠、银灯笼、锁头、对勾）**代替 `"01 ★ 可玩"`、`"1/6 满3通行"` 等干瘪文字。
3. **大厅与选关背景随当前选中地图实时换肤 + 播放动态生态**：当玩家在闯关模式切换到“2. 迷雾古森”时，整个选关界面的背景立刻变为古树萤火虫与飞舞蝴蝶；切换到“5. 云端圣域”时，背景立刻变为破晓霞光与缓缓飘动的流云！

## 4. 六大风格地图「去火柴盒化」重设计规范（告别千篇一律横梁）

当前设计的地图最大的毛病是**“外框一个死长方形 + 里面几根水平直线横梁”**，所有地图的几何轮廓完全雷同。本次重设计在不破坏任何物理可解性的前提下，赋予每张地图**一眼可辨的地貌轮廓（Silhouette Identity）**：

| 地图风格 | 旧版地形缺陷 | **重设计后的地貌轮廓与地图结构特征** |
| :--- | :--- | :--- |
| **1. 迷雾古森**<br>(`forest`) | 方盒子外框 + 水平隔板，毫无森林感 | **「千年巨木空洞与阶梯树冠」**：<br>- 打破四角方框，左上与右上向内收拢形成**拱形树冠穹顶**；<br>- 地面采用**高低错落的自然草坡（1 格阶梯渐进）**而非全平地板；<br>- 中央立柱改为粗壮的“中空古树干”，水池设计为底部圆弧形的林间深潭，草皮顶面遍布野花、知更鸟与翩跹蝴蝶。 |
| **2. 云端圣域**<br>(`sky_island`) | 四周或底部有厚重实心墙，不像浮在空中 | **「四面无边框的纯浮空群岛」**：<br>- **彻底去掉左右与顶部的实心外墙**！整张地图由 3–5 座完全悬空在破晓云海中的独立白色大理石浮岛组成；<br>- 每座浮岛底部呈**倒梯形/锥形岩托 + 3px 蓬松白云包边**，岛与岛之间完全靠高空冰桥、浮云软垫和顺风沙桥连接，背景三层白云持续飘过。 |
| **3. 黄金神庙**<br>(`ruins`) | 普通长方形房间，看不出神庙与金字塔结构 | **「正金字塔阶梯内殿与对称神坛」**：<br>- 外轮廓采用**上窄下宽的金字塔阶梯斜坡墙**（左右两侧按 `y` 逐层向外扩宽）；<br>- 顶部正中为流沙漏斗天窗（细金沙持续漏下），中央为宏伟的对称天平大殿，底层两侧为绿洲圣水池，石台边缘燃烧圣火盆并有圣甲虫爬行。 |
| **4. 幽光晶窟**<br>(`cave`) | 横平竖直的人工砖墙，不像天然溶洞 | **「犬牙交错的钟乳石溶洞与斜向矿脉」**：<br>- 洞顶与洞底采用**不规则锯齿状/波浪状岩层厚度**（洞顶向下探出长短不一的钟乳石群，洞底向上突起石笋）；<br>- 左高右低的天然斜坡水道引导强酸漫灌，岩壁嵌满呼吸闪烁的青/紫水晶簇与飞舞的水晶蛾，底部左酸池（绿泡）右熔岩（红光）形成强烈冷暖对比。 |
| **5. 深空星站**<br>(`cosmos`) | 和地牢一样的石墙布局，缺乏太空舱结构感 | **「八角形斜切太空舱段与全景星空观察窗」**：<br>- 舱室四角采用 **45° 斜切装甲倒角**；<br>- 舱室中央留出大面积透明背景区，露出后方旋转的小行星带、紫蓝星云与巡航维修无人机；<br>- 上下对称布置磁吸导轨与黄黑警示平台，配合红色激光护盾门与发光量子传送座。 |
| **6. 幽暗石牢**<br>(`dungeon`) | 布局过于局促单调 | **「多层拱顶地下城与垂直升降矿井」**：<br>- 顶部石墙采用古典地下城拱券凹凸结构，墙壁悬挂摇曳火把与垂挂铁链，洞顶偶有小蝙蝠眨眼与水滴落下，强化经典地牢氛围。 |

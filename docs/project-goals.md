# 推箱项目目标与需求记录

更新日期：2026-10-14（Asia/Shanghai）。

成品要保持当前像素美术方向和简单、易上手的操作，同时让 SDK 的元素反应、流体和刚体能力成为玩家解决问题、应对危险的核心。游戏计划包含教学、闯关、挑战三个模式；挑战模式从第一关起，每关都保持地狱难度，并使用更大的地图、陷阱和怪物。

本文作为后续补充目标的固定入口。用户已明确的目标、用户试玩反馈、参考游戏事实和设计建议分别记录。后续有新要求时更新对应条目，并在末尾保留日期与变更说明。与旧 Demo 规范冲突时，以用户最新要求为准。

## 三大阶段推进规划（设计与 GPT 开发分离）

用户已明确后续按**三大阶段**推进，设计侧只负责方案设计与审核，开发执行全权交给 GPT / Codex（详见 [三大阶段开发总规划](superpowers/plans/2026-10-14-three-modes-and-mechanisms.md) 与 [关卡设计方案](mode-and-level-design.md)）：

1. **第一阶段（当前优先）**：
   - **美术全改为纯代码生成**：所有精灵/UI 改为 GDScript 启动时代码生成内存贴图，地形全走 `world.gdshader` 纯代码渲染。
   - **优先制作教学模式（`T01–T04` 共 4 个简单关卡）**：不用一一罗列衍生机制，只用 4 个简单关卡快速演示并覆盖大致核心玩法操作（移动/登阶/爬梯/推箱、左键挖沙/右键倒沙、拉杆放水/投沙抬水、压板/拖炸药爆破）。
2. **第二阶段（第一阶段完成后启动）**：
   - **闯关模式增量解谜**：根据不同特性分章节设计增量解谜关卡，把 SDK 现有的其他特性（铁箱、酸蚀、水火化沙、结冰相变、燃烧、电路、瞬态刚体崩落等）逐步加进来。
   - **设计并扩展 SDK 新特性**：设计当前 SDK 没有的新特性（如休眠水无损唤醒、忽略周期电路的静止判定、方向性/温度条件反应、持续风场、流体流量传感等），设计好后由用户去 SDK 添加这些扩展内容，再融入关卡。
3. **第三阶段（最后大阶段）**：
   - **地狱挑战模式**：把闯关模式里的所有特性（含新增 SDK 扩展特性）全部糅合起来，配合 `640×384` 多房间连通大地图、陷阱和怪物，拉满解谜难度。

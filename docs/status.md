## 已复现、修复并复测的问题

1. **检查点拒绝合法存档**：Godot字典dot赋值产生StringName文本键，JSON兼容校验只接受String。修为兼容String/StringName键与文本值，其余形状、UID、SHA和原子提交校验保留。M05动作后实际写出主备检查点；退出重启后“继续”恢复人物[3,3]/moves1，重开再撤销也正确。原“游戏无法启动: Checkpoint requires…”警告不再出现。
2. **W01原六步不能通关**：真实旧快照水512守恒、木箱只到[5,6]、上格水64、下方水头0。最小修正为[4,5]挡水唇、井内两格背景梯子；水量、机关规则、阈值及RRURRR不变。原生窗口六步通关，并撤销放水恢复原池/木箱后再走通；胜利快照水512、crate256。误入井安全梯子已写规格，本轮没有单独走完整误入井分支。
3. **W09原七步不能通关**：旧水1536守恒，但箱上90cell、水头22，均未到既定浮升条件。只把开局水增加一格[6,2]至1792，原地图/传送/阈值/RRLUUUR不变；不在运行时生成水。首R木箱实际浮到[7,2]，原七步通关；胜利快照水1792、crate256。
4. **G01酸蚀后堵路**：旧剩酸263=剩软岩263，四邻接触0，酸落到岩下后失联。仅去掉下层一格软岩，保持原512酸、上层256软岩和五步路线；不改反应或128分类阈值。复测五步通关；SDK仍有112软岩和368酸（差256），没有伪造“全岩消失”或强行删残岩。
5. **选关长说明被截断**：旧W01说明实际截断并报paragraph clipped。改为完整文本的独立滚动区，PageUp/PageDown可滚，地图预览不动、左侧选择焦点保留。实窗PageDown读到最后“台阶。”，未再报相关布局警告。
6. **重启大厅章节错误**：以前“继续”指向后章，背景/章节仍显示第一章。启动时只读恢复可访问的上次章节/关卡选择，不写进度。最终同PCK隔离窗口已显示第四章森林与继续G01。

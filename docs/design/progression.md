# 局外养成（设计稿）

状态：设计稿，配送模式与地狱模式共用。总纲见 [vision.md](vision.md)，参考来源见 [参考资料](../research/2026-10-15-mode-references.md)。

## 1 原则

- **以解锁和多样性为主，数值为辅**。调研的共识是：养成太弱没有意义，太强会让单局挑战变得太简单，它应当增强以技巧为核心的玩法，而不是取代它。
- **关卡模式不受养成影响**：它是机制的试验场，必须对所有人一样。通关只发收藏品（邮票）。
- **地狱模式只发奖励，难度不受养成影响**：谜题不能靠数值解决。
- **配送模式受养成影响**，但永久数值加成有上限（第 4 节）。
- **失败也有收获**：配送失败时带回一部分邮票和小费。

## 2 货币与资源

| 名称 | 从哪里来 | 用在哪里 |
|---|---|---|
| 小费 | 配送模式局内：拾取、放倒怪物、送达 | 局内驿站购买道具和增益；结算时按比例转成工资 |
| 工资 | 配送结算 | 执照升级、装备、驿站建设、外观 |
| 地狱币 | 地狱模式通关、步数挑战 | 地狱外观、配送模式特权 |
| 邮票 | 三个模式都有：关卡模式通关、配送模式隐藏收集、地狱模式隐藏收集 | 邮票册（收藏），集齐一套给外观 |
| 执照经验 | 配送送达次数与评级 | 执照等级 |

## 3 养成内容

1. **执照等级**：解锁新区域（按主题顺序）、新货物（更难的规则）、更大的地图。
2. **装备**：起始道具槽、手推车、绳梯、背包容量等，影响配送模式的开局。
3. **驿站**：在各区域建设驿站，配送模式中出现驿站房间（补给、换单、存小费）。名字取自罗马驿传沿路的换马站。
4. **收藏**：邮票册（按区域和模式分册）、收件人档案（感谢信与小故事）、怪物图鉴。
5. **外观**：制服、帽子、包、手推车涂装；地狱模式专属外观。

## 4 数值边界

- 永久数值加成（例如冰淇淋融化速度、被怪物碰到的损伤）累计最多 20%。
- 执照满级后开放"加急件"难度阶：更紧的时限、更多怪物、更高报酬（借鉴 Dead Cells 用难度阶做后期进度）。

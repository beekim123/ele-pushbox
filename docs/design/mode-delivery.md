# 配送模式（设计稿）

状态：设计稿，**关卡模式完成后才开工**。货物、怪物、道具、增益的清单以 `content/catalog/` 中的目录文件为准（工作台「设计数据」页），本文表格只作说明。本文给出方向和约束，不是开发规格；开工前先按第 8 节做技术样板，再写详细规格。总纲见 [vision.md](vision.md)，参考来源见 [参考资料](../research/2026-10-15-mode-references.md)。

## 1 一局的流程

接单 → 出发 → 穿过若干房间 → 送达或失败 → 结算 → 局外养成。

- **接单**：开局从已解锁的货物池里随机抽一件货物，配一位收件人和一个区域（主题）。
- **路上**：地图由多个一屏大小的房间拼成。玩家用关卡模式学过的机制、背包道具和本局增益前进，避开或放倒怪物，顺路收集小费和邮票。
- **送达**：把货物带进收件人所在的房间并交到收件人手里。结算看货物完好度、用掉的回合数和收集。
- **失败**：货物损坏到 0、超出时限、或人物被怪物抓住（见第 4 节）。失败也能带回一部分收集（见 [局外养成](progression.md)）。
- **时长**：一局 10–20 分钟。

**回合制不变**：沿用格子移动和"动作 → 结算 → 再操作"的节奏。怪物在玩家每次行动、结算结束之后各走一步，不要求反应速度。货物的"时间"按回合计，玩家思考时不流逝（第 9 节第 1 条）。

## 2 货物：每件货物带一条规则

每种货物只加**一条**主规则，规则状态显示在 HUD 上（进度条或图标），并且只用关卡模式验证过的机制。新货物先在关卡模式的"货物实验组"做一个小关卡验证，再放进抽取池。

| 货物 | 规则 | 怎么应对 | 用到的机制 | 难度 |
|---|---|---|---|---|
| 信件 | 很轻，可以和别的东西一起拿；落水会湿，完好度下降 | 绕开水，或找防水袋 | 水 | 入门 |
| 冰淇淋 | "融化度"每回合增加，靠近火盆、热喷口、燃烧的格子时增加更快，到 100% 失败 | 冷凝喷口、冰块、保冷箱降温；规划短路线 | 冷与热 | 中 |
| 大件货物（沙发、钢琴） | 双手抬着：每走一格算两回合（怪物走两步），不能爬梯、不能挖、不能倒沙；放下后才能做别的事 | 找手推车（取消减速）、力气饮料（若干步内不减速）；用升降台运；木质大件可以放在水上漂过去 | 升降台、浮箱 | 高 |
| 易碎品（花瓶、鸡蛋） | 从 2 格及以上落下就碎；附近爆炸会碎；落在沙上不碎 | 搭台阶、走梯子、先倒沙做垫子 | 沙、爆炸 | 中 |
| 鱼缸 | 每隔若干回合要在水边"补水"一次，否则完好度下降 | 规划经过水的路线 | 水 | 中 |
| 热汤 / 披萨 | 温度随回合下降，靠近火回升；凉了只少给小费，不算失败 | 顺路经过火盆 | 冷与热 | 低 |
| 炸药包 | 碰到火就爆（失败），从 2 格及以上落下也会爆 | 绕开火源，下落走梯子 | 燃烧、爆炸 | 高 |
| 气球花束 | 放下后会往上飘，直到碰到天花板；可以先让它飘上高台，自己再爬上去拿 | 利用上浮把货物先送到高处 | 上浮（游戏层） | 中 |
| 盆栽 | 收件人要活的：途中至少浇一次水；碰到酸液或火就枯萎 | 找水，绕开酸和火 | 水、酸、火 | 低 |
| 秘密文件 | 被巡逻者"看见"（同一行且中间没有遮挡）就会被抢走 | 用箱子、墙挡住视线，等对方转身 | 怪物视线 | 高 |

## 3 地图：小房间拼成大地图

- **一屏一房间**：每个房间 20×10 格（320×180），和关卡模式的房间一样大。SDK 世界正好是一屏，所以每个房间是一个独立的 SDK 世界；离开房间时保存快照，回来时恢复。
- **区域**：一局在一个区域（主题）里进行，后期可以跨两个区域。
- **房间模板**：手工设计。每个模板标明边缘出入口的位置（每条边固定几个口位，相邻房间的口位必须对上，借鉴 Noita 的 Wang 砖），以及它在路线上能担任的角色（左右通道、下落、上爬、转角、起点、收件人房、驿站、宝物房）。每个模板对它的每一对出入口都要附一条作者解。
- **生成**（借鉴 Spelunky）：房间网格 3×3 到 4×4；先放起点房和收件人房，随机走出一条主路径；主路径上的格子按角色从模板池里抽房间；主路径以外放宝物房、驿站和可选的怪物房。
- **可通性保证**：主路径只靠模板自带的作者解就能走通，不依赖随机掉落的道具。因为每个模板单独验证过、相邻口位又对得上，所以生成出来的地图必然可通；生成器再用格子模型检查一遍。
- **镜头**：一屏一房，走出边缘时滑屏切换。HUD 上有小地图，显示已走过的房间和收件人方向。

## 4 怪物：回合制，用环境对付

怪物在玩家每次行动并结算之后走一步。没有攻击键，处理怪物全靠环境（借鉴 Lode Runner 的挖坑困敌、落物压敌）。

| 怪物 | 行为 | 对付办法 |
|---|---|---|
| 巡逻者 | 沿地面左右走，碰墙回头 | 绕开；挖坑困住；推箱子或倒沙压住 |
| 追踪者 | 每回合朝玩家靠近一格（只走地面和梯子） | 引进坑、水或冰面 |
| 守门者 | 守在通道口不动，推不动 | 炸开旁边的裂岩绕过去；用水冲走 |
| 飞行者 | 不受重力，直线飞，碰墙折返 | 用烟雾驱散；等它飞过 |
| 偷件者 | 专门抢秘密文件，视线是一整行 | 遮挡视线 |

- **放倒**：被箱子、沙、碎石压住，掉进坑里，被水淹没若干回合，被冻住或烧到，就会倒下若干回合或直接消失，并掉落小费或邮票。
- **被碰到**：货物完好度下降一档，人物退回上一格。不设血量，避免和完好度重复。

## 5 道具与增益

- **背包道具**（消耗品）：沙袋、炸药（已有）、绳梯（放一段梯子）、木板（在一格宽的缺口上搭桥）、冰块（给冰淇淋降温）、诱饵（吸引追踪者）。
- **本局增益**：手推车（大件不减速）、力气饮料（若干步内大件不减速）、保冷箱（融化速度减半）、护垫（易碎品防摔一次）、防水袋（不怕水）、指南针（小地图显示收件人方向）。
- **来源**：房间里拾取、放倒怪物掉落、在驿站用小费购买。

## 6 局内收集与结算

- **小费**：拾取、放倒怪物、送达时获得；本局在驿站使用，结算时按比例转成工资（局外货币）。
- **邮票**：每个区域一套，藏在需要额外思考才能拿到的位置，进入局外的邮票册。
- **收件人的感谢信**：送达后获得，逐步解锁每位收件人的小故事。
- **结算**：报酬 = 基础报酬 × 完好度系数 × 用时系数 + 小费；给出评级。失败时只带回部分邮票和小费。

## 7 局外养成

见 [progression.md](progression.md)：执照等级解锁新区域和新货物，装备增加起始道具，驿站提供补给点，邮票册和外观提供收藏目标。

## 8 开工前的技术样板

1. **房间切换**：每个房间一个 SDK 世界，离开时存快照，返回时恢复，往返结果一致（不使用刚体，SDK 带刚体的快照不保证位级一致）。
2. **结算顺序**：玩家行动 → SDK 结算 → 怪物行动 → 怪物引起的材料变化再结算；整局可以重放。
3. **房间模板格式**：在关卡规格上加 `exits`（每条边的口位）和 `roles`；每对出入口一条作者解。
4. **生成器与验证器**：先在 Node 工具里实现，同一个种子生成同一张地图；工作台可以按种子预览生成结果。
5. **单局存档**：中途退出后能继续这一局。

## 9 待定问题

1. **时限按回合还是按真实时间**：建议按回合。思考不消耗时间，符合"思考多于执行"；真实时间会让冰淇淋变成手速考验。
2. **能不能撤销**：建议本房间内可以撤销，离开房间后不能撤回；局外养成可以增加"回溯"次数。
3. **失败惩罚**：建议带回一半邮票和小费，不损失局外已有的东西。

# 配送模式（核心内容，设计稿）

状态：设计稿，关卡模式完成后开工（第 1 层先做技术样板，见第 14 节）。**第一个可玩切片**（幽暗石牢：3 货物 × 3 收件人、2 种怪物、约 9 个房间模板）见 [delivery-slice.md](delivery-slice.md)，正在按步骤推进。清单以 `content/catalog/` 为准：`cargo`、`recipients`、`combos`、`worlds`、`monsters`、`items`、`buffs`、`events`、`slices`（工作台「设计数据」页）。世界观见 [总纲](vision.md)，地区见 [worlds.md](worlds.md)，角色见 [characters.md](characters.md)，养成见 [progression.md](progression.md)。

## 1 定位

一局是一次跨世界送货：**滚轮定单 → 穿越地图 → 亲手送达 → 带着收获回渡口**。它把关卡模式学过的机制放进有压力的冒险里：怪物在追，冰淇淋在化，钢琴很重，路要自己找。每局都不一样，因为货物、收件人、地区、地图、事件都会变。

## 2 一局的流程

1. **渡口准备**：在商店买道具、在工坊升级、装上徽章；选好要带进这一局的道具（受背包格数限制）。
2. **双滚轮定单**：招财猫拉下拉杆，两个滚轮转动，停下后得到这一单的**货物**和**收件人**（第 3 节）。收件人决定去哪个地区，货物决定这一路的特殊规则。
3. **穿过渡门**：来到收件人所在的地区。地图由若干个一屏大小的房间拼成（第 6 节）。
4. **路上**：解谜开路、对付怪物（第 7 节）、拾取金币和道具、在驿站购物、遇到随机事件、接顺路单（第 9 节）。
5. **送达**：把货物交到收件人手里。收件人的反应和小费取决于完好度、用时和缘分组合（第 11 节）。
6. **连送或回家**：可以见好就收，带着全部收获回渡口；也可以接着送下一单，难度和报酬倍率一起上升（第 10 节）。
7. **结算**：金币、执照经验、邮票、收件人好感、谢礼带回渡口（[progression.md](progression.md)）。

单局目标时长 15–25 分钟（含连送）。失败（人物倒下、货物全损、超时）只带回一部分收获。

## 3 双滚轮

### 3.1 滚轮

- **货物轮**和**收件人轮**各有一圈符号。符号分常见、稀有、传说三档；传说符号（如龙王、钢琴）出现得少，报酬高。
- 收件人决定地区（例如大象 → 草原象谷，僵尸 → 墓园鬼镇，外星人 → 星际港）；货物决定特殊规则（例如冰淇淋会化、钢琴让人变慢）。
- 已解锁的货物和收件人才会出现在滚轮上。新的符号通过执照等级、商店和成就解锁（[progression.md](progression.md) 第 5 节），所以滚轮会越来越丰富。

### 3.2 玩家能做什么

借鉴老虎机和以老虎机为核心的肉鸽游戏《Luck be a Landlord》（重转令、移除令让玩家改变随机结果）：

| 操作 | 效果 | 来源 |
|---|---|---|
| 重转 | 重新转其中一个滚轮 | 每局若干张重转券（属性升级） |
| 锁定 | 重转时保留一个滚轮不动 | 执照等级解锁 |
| 推一格 | 把某个滚轮往前或往后推一格，看得见相邻的符号 | 推格券（商店、事件），呼应推箱的"推" |
| 加注 | 主动选"加急"，难度和报酬一起升 | 加急令（[progression.md](progression.md) 第 7 节） |

第 4 层再加**第三个滚轮：委托条件**（加急、匿名、夜间、惊喜、双份、保密、反向……），三个符号组合出更多变化。

### 3.3 缘分组合

某些货物和收件人凑在一起会触发特殊效果，清单在 `content/catalog/combos.json`。例子：

| 货物 × 收件人 | 效果 |
|---|---|
| 冰淇淋 × 雪人 | 冰淇淋不会化，但小费少（太容易了） |
| 冰淇淋 × 火精灵 | 越靠近收件人化得越快，送到了小费 ×3 |
| 脑子罐头 × 僵尸 | 一路上的僵尸都闻得到，会追着你跑 |
| 鱼 × 猫 | 路上的野猫会来偷；猫收件人超级开心 |
| 情书 × 幽灵 | 只有在灯光下才能看见收件人 |
| 气球花束 × 小孩 | 丢了一个气球，小孩会哭，小费减半 |
| 月饼 × 玉兔 | 月宫低重力；送到后给一块特殊谢礼 |
| 花生 × 大象 | 大象亲自出门来接你，最后一个房间省掉 |
| 钢琴 × 老奶奶 | 老奶奶住在三楼，但楼里有货梯 |
| 蜂蜜 × 熊 | 蜂群和熊都会被吸引 |
| 外星蛋 × 外星人 | 蛋在路上会孵化成一只跟着你走的小外星宠物 |

缘分组合要让玩家记住、期待，也可以作为成就和图鉴的收集目标。

## 4 时间与操作：按格移动 + 实时世界

- **世界持续运转**：SDK 每帧推进，沙会落、水会流、火会烧；怪物按自己的节奏行动；货物计时器以秒计。
- **人物按格移动，两步之间有"移动间隔"**（2026-10-15 用户确定）：人物一次走一整格（约 0.1 秒的走路动画），之后有一小段停顿，停顿结束前不能走下一格。按住方向键，会在停顿结束的那一刻自动走下一格；在停顿中按下的方向会记住一次（输入缓冲），所以操作不会"吞键"；松开就停在格子上。
- **移动速度 = 缩短移动间隔**：移动间隔 = 基础间隔 × 地形倍率 × 货物倍率 × (1 − 加成)。

| 动作 | 基础间隔 |
|---|---|
| 走一格、攀爬一格 | 0.22 秒 |
| 推一格 | 0.30 秒 |
| 挖一格、倒一格沙 | 0.35 秒 |
| 放炸药、拉杆、用道具 | 0.40 秒 |

| 倍率 | 数值 |
|---|---|
| 抬大件（钢琴、沙发等） | ×2（力气饮料、手推车减为 ×1.4） |
| 泥地 | ×2 |
| 浅水 | ×1.5 |
| 冰面 | 不受间隔控制：一直滑到撞上东西为止 |

| 加成（相加，合计最多 35%） | 数值 |
|---|---|
| 工坊属性"移动速度" | 每级 5%，最多 25%（走一格 0.165 秒） |
| 本局增益"跑鞋" | 10% |
| 徽章"快手" | 只缩短推、挖、倒、放的动作间隔 |

  上限是为了不让人物快到看不清、也不让养成破坏谜题节奏。所有间隔都是数据（`content/catalog/upgrades.json`、`buffs.json`），可以在工作台调整。
- **随时暂停**：暂停时可以看地图、看收件人信息、整理背包。
- **重来这个房间**（2026-10-15 切片设计时加入）：实时模式没有撤销，暂停菜单里可以让当前房间和人物状态回到这次进门时，只有时间不倒流，防止把自己卡死（[delivery-slice.md](delivery-slice.md) 第 2 节）。
- **辅助选项**：设置中提供"从容模式"（全局 70% 速度）和"时停怀表"（站着不动时时间几乎停止，移动时才正常流动），让偏解谜的玩家也能玩。时停怀表也可以作为道具出现。
- **先例**：《Boulder Dash》按格挖掘，落石会压扁敌人，也会压到自己，每个洞穴都有时限；《炸弹人》按格移动，加速鞋（缩短移动间隔）、炸弹数量、火力范围都是有上限的拾取道具。
- 关卡模式与地狱模式保持回合制，不受影响。

## 5 生命、货物完好度与失败

- **生命**：人物有若干颗心（基础 3 颗，可升级）。被怪物碰到、被落物砸到、被火烧到、被酸腐蚀都会掉心，之后有短暂无敌时间。心掉光 = 本单失败（徽章、道具可以救一次）。
- **货物完好度**：货物有自己的耐久（基础 3 格），受伤时可能连带受损，易碎品摔了会受损，冰淇淋化掉也算受损。完好度归零 = 本单失败。
- **超时**：只有带计时规则的货物（或加急令）才有时限。
- **失败的后果**：本局获得的金币带回 50%，邮票全部带回，好感不变。徽章"运费险"可以提高带回比例。

## 6 地图：房间拼成大地图

- **一屏一房间**：每个房间 20×10 格（320×180），和关卡模式一样大。SDK 世界正好一屏，所以每个房间是独立的 SDK 世界；离开房间时保存快照，回来时恢复。
- **房间网格**：一张地图 3×3 到 5×4 个房间。先放渡门（起点）和收件人之家（终点），随机走出一条主路径；主路径上的房间按"角色"（左右通道、下落、上爬、转角）从手工模板池抽取（借鉴 Spelunky：主路径保证不用道具也能走通，其他房间可能封闭）。
- **口位对接**：模板每条边有固定的出入口位置，相邻房间的口位必须对上（借鉴 Noita 的 Wang 砖拼接）。左右的出入口是两格高的开口；上下的出入口是两格宽的双梯子竖井，人在房间之间爬上爬下，不会从一个房间掉进另一个房间（切片第 7 节）。
- **房间类型**：渡门、通道、谜题房、驿站（商店 + 回一颗心）、宝箱房、事件房、强敌房、收件人之家。收件人之家有时本身就是一道小谜题（例如钢琴要送上三楼）。
- **可通性保证**：每个模板对它的每一对出入口都附一条作者解，并在关卡模式的格子模型或 SDK 回放中验证过；口位对得上，所以生成的地图必然可通。生成器用种子，同一种子生成同一张图，工作台可以按种子预览。
- **镜头**：一屏一房，走出边缘滑屏切换；HUD 上有小地图，显示走过的房间、收件人方向和已知的驿站。

## 7 怪物：推它、压它、困住它

没有攻击键。对付怪物的办法都来自环境和已经学过的动作：

| 办法 | 怎么做 | 来自哪个机制 |
|---|---|---|
| **推怪** | 小怪可以像箱子一样被推一格，推进坑里、水里、火里、刺上 | 推箱 |
| **压怪** | 挖掉箱子、沙、碎石下面的支撑，让它们砸下去 | 失去支撑、碎石 |
| **困怪** | 挖坑让怪掉进去，它被困一会儿后自己爬出来；趁它被困，把挖出的沙倒回坑里就埋住它（借鉴 Lode Runner；2026-10-15 改为坑不自己填回，见切片第 6 节） | 挖取、倒沙 |
| **淹 / 烧 / 冻 / 蚀** | 引水、点火、冷凝、引酸 | 水、燃烧、冷凝、酸蚀 |
| **炸** | 炸药 | 爆破 |
| **引开** | 诱饵、货物的气味、声音 | 道具、缘分组合 |
| **躲开** | 等它转身、绕路、挡住视线 | — |

- 被放倒的怪会掉落金币，偶尔掉道具。大怪推不动，只能用环境对付或绕开。
- 每个地区有自己的怪物（[worlds.md](worlds.md)），例如乡村的看门狗和稻草人、墓园的僵尸和鬼火、星际港的巡逻无人机。
- 怪物的行为必须一眼看懂：巡逻、追踪、守门、飞行、偷东西、伏击，各有固定的动作和提示动画。

## 8 道具、增益、金币与商店

- **金币**：放倒怪物、打开宝箱、完成顺路单、送达小费都给金币。局内在驿站花；局外在渡口商店和工坊花（[progression.md](progression.md)）。
- **背包道具**（消耗品，占背包格）：沙袋、炸药、绳梯、木板、冰块、诱饵、水桶、火柴、灭火器、雨伞（缓降）、弹簧鞋（向上弹一格半）、磁铁、灯笼、回溯沙漏（倒回 5 秒，用 SDK 快照实现）、封条（封住一扇门或定住一只怪）、传送信标、地图碎片、急救包。
- **本局增益**（拾取或购买，到本局结束）：手推车、力气饮料、保冷箱、护垫、防水袋、指南针、跑鞋、夜视、幸运签。
- **驿站**：地图里的商店房，回一颗心，卖道具和增益；越往深处价格越高。
- 清单与数值草案见 `content/catalog/items.json`、`buffs.json`。

## 9 随机事件与顺路单

- **事件房**：遇到一个场景，给两三个选择（借鉴肉鸽游戏的问号房间）。例子：路边算命先生（花金币重转收件人）、迷路的小孩（帮他找妈妈，耽误时间但给好感）、掉进井里的猫、桥断了（付钱绕路或自己修）、一场突来的雨（火都灭了，地面变滑）、神秘商人（用心换稀有道具）。清单见 `content/catalog/events.json`。
- **顺路单**：路上的居民托你顺路带个小东西，占一个背包格，送到就给金币和好感。背包格数因此很有意义。

## 10 连送

送达后可以选择：

- **回家**：带着全部收获回渡口。
- **再送一单**：当场再转一次滚轮，难度提升一档，报酬倍率 +0.5；如果下一单失败，这一轮连送累积的倍率奖励只带回一半。

连送让玩家自己决定冒多大的险，也是高手拿高分的地方。

## 11 送达、评分与好感

- **小费** = 基础报酬 × 完好度系数 × 用时系数 × 缘分组合系数 + 顺路单。
- **评级**：S / A / B / C，记录在收件人档案里。
- **收件人好感**：同一位收件人送得越多、评级越高，好感越高。好感会解锁收件人的小故事、寄来谢礼（渡口装饰）、给出专属缘分组合，最高好感时收件人会在地图上出手帮忙一次（例如大象用鼻子喷水灭火）。

## 12 与关卡模式的关系

- 配送模式只能使用关卡模式里已经"可玩"的机制。地区专属的新机制（低重力、冰面滑行、传送兔子洞、缩小蘑菇……）先在关卡模式的实验组各做一关并验证（[game-design.md](game-design.md) 6.7），再进入配送模式。
- 房间模板沿用关卡规格的格式，另加 `exits`（每条边的口位）和 `roles`（能担任的路线角色）。

## 13 平衡原则

- 主路径必须不靠道具也能走通；道具和增益让路更好走、更快、更安全，或者打开支线和宝箱。
- 养成有上限，加急令负责给强玩家新的挑战（[progression.md](progression.md)）。
- 任何货物规则都要在 HUD 上看得见（进度条或图标），不靠玩家记忆。

## 14 开工前的技术样板

1. **按格移动 + 实时 SDK**：每帧推进 SDK，人物按格移动并遵守移动间隔，推箱、挖、倒在实时下的表现与关卡模式一致；记录帧耗时。
2. **房间切换**：每个房间一个 SDK 世界，离开时存快照，回来时恢复，往返结果一致（不使用刚体）。
3. **怪物**：在格子上按固定规则行动，能被推、被压、被困、被淹；行为可以重放。
4. **生成器与验证器**：先在 Node 工具中实现，同一种子同一张图；工作台按种子预览。
5. **单局存档**：中途退出后能继续这一局。

# 万界渡口与各个地区（设计稿）

状态：设计稿。地区清单与字段以 `content/catalog/worlds.json` 为准，地区专属机制登记在 `content/catalog/mechanisms.json`（状态"提议"，属于实验组）。总纲见 [vision.md](vision.md)。

## 1 渡口

万界交汇处的一座小渡口，是配送模式的"家"，也是全部模式的入口：

| 地方 | 作用 | 对应模式 / 系统 |
|---|---|---|
| 招财猫滚轮台 | 拉杆转出货物和收件人 | 配送模式 |
| 渡门大厅 | 一排渡门，每扇通往一个地区；新地区解锁时多一扇门 | 配送模式 |
| 龟掌柜的店 | 背着整间铺子的老乌龟，卖道具、解锁新货物 | 商店 |
| 工坊 | 修补匠帮你升级属性 | 属性养成 |
| 徽章柜 | 装卸徽章 | 徽章 |
| 邮局 | 收件人寄来的感谢信和小故事 | 收件人好感 |
| 训练场 | 六块场地，每块练一组机制 | 关卡模式 |
| 冥河码头 | 老渡夫的小船，通往地底九层 | 地狱模式 |
| 展览角 | 摆放谢礼、邮票册、怪物图鉴 | 收藏 |

渡口的视觉：木栈道、灯笼、挂满各国邮票的告示板、各地区谢礼堆成的小景。它本身就是"多文化融合"的展示窗。

## 2 地区设计规则

1. **一个地区一种风格**：每个地区内部美术统一，地区之间可以完全不同。
2. **每个地区带 1–2 个专属机制**，先在关卡模式实验组做成关卡并验证，才能进配送模式。
3. **每个地区 2–3 种怪物、2–4 位收件人**，怪物的对付办法要和本地区的机制呼应。
4. **共用规则不变**：所有地区都用同一套格子规则、材料和机关；地区只是换皮加专属机制。
5. **美术需求**：一个主题资产（地形图案、背景、生态）、本地区的植物与小动物、怪物、收件人、专属机关，全部走确认流程。

## 4 地区专属机制（提议）

以下机制都登记在机制目录里，状态是"提议"。进入配送模式前，每个都要在关卡模式实验组做成一关并验证。

| 机制 | 归属 | 说明 | 风险 |
|---|---|---|---|
| 泥地减速 | 游戏层 | 站在泥上移动速度减半 | — |
| 冰面滑行 | 游戏层 | 在冰上移动会一直滑到撞上东西 | 与 SDK 冰材料共用 |
| 低重力 | SDK + 游戏层 | 落得慢，人能安全落下更多格 | 需要 SDK 支持按世界调重力 |
| 黑暗与灯光半径 | 游戏层 | 黑暗地区只看得见灯光照到的范围 | — |
| 兔子洞传送 | 游戏层 | 成对的洞口互相传送人和货物 | — |
| 缩小 / 放大 | 游戏层 | 缩小后能钻半格高的通道，但推不动箱子 | 格子规则要支持半格，复杂度高 |
| 弹跳蘑菇 | 游戏层 | 落到蘑菇上被弹起若干格 | — |
| 传送带 | 游戏层 | 持续把上面的人和箱子往一个方向送 | — |
| 潮汐 | SDK + 游戏层 | 水位按节奏涨落 | 大量写水，性能要测 |
| 流沙 | SDK + 游戏层 | 站在流沙上会慢慢陷下去 | — |
| 焦油 | SDK | 很稠的液体，进去会被粘住 | 需要 SDK 的黏度能力 |
| 熔岩 | SDK | 会流动、会点燃的液体 | 温度与燃烧联动要测 |
| 磁力 | 游戏层 | 磁铁吸引铁箱 | — |
| 激光与镜子 | 游戏层 | 激光被镜子反射，照到开关打开机关 | — |
| 移动平台 | 游戏层 | 小船、飞剑、河马按路线移动，可以站在上面 | 与浮箱规则配合 |
| 昼夜 | 游戏层 | 有的东西只在夜里出现或活动 | — |
| 雪球 | 游戏层 | 推动雪球会越滚越大，变成能压怪的大球 | — |
| 气泡托举 | SDK + 游戏层 | 水下的气泡能把人和轻货托上去 | — |
| 水下与氧气 | 游戏层 | 在水里有氧气条 | — |
| 冷暖值 | 游戏层 | 寒冷地区要靠火堆取暖 | — |
| 推怪 / 压怪 / 困怪 | 游戏层 | 配送模式的核心应对办法（[mode-delivery.md](mode-delivery.md) 第 7 节） | — |

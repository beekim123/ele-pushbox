## 1 渡口

万界交汇处的一座小渡口，是配送模式的"家"，也是全部模式的入口：

| 地方 | 作用 | 对应模式 / 系统 |
|---|---|---|
| 招财猫滚轮台 | 拉杆转出货物和收件人 | 配送模式 |
| 渡门大厅 | 一排渡门，每扇通往一个地区；新地区解锁时多一扇门 | 配送模式 |
| 龟掌柜的店 | 背着整间铺子的老乌龟，卖道具、解锁新货物 | 商店 |
| 工坊 | 修补匠帮你升级属性 | 属性养成 |
| 徽章柜 | 装卸徽章 | 徽章 |
| 邮局 | 收件人寄来的感谢信和小故事 | 收件人好感 |
| 训练场 | 六块场地，每块练一组机制 | 关卡模式 |
| 冥河码头 | 老渡夫的小船，通往地底九层 | 地狱模式 |
| 展览角 | 摆放谢礼、邮票册、怪物图鉴 | 收藏 |

渡口的视觉：木栈道、灯笼、挂满各国邮票的告示板、各地区谢礼堆成的小景。它本身就是"多文化融合"的展示窗。

## 2 地区设计规则

1. **一个地区一种风格**：每个地区内部美术统一，地区之间可以完全不同。
2. **每个地区带 1–2 个专属机制**，先在关卡模式实验组做成关卡并验证，才能进配送模式。
3. **每个地区 2–3 种怪物、2–4 位收件人**，怪物的对付办法要和本地区的机制呼应。
4. **共用规则不变**：所有地区都用同一套格子规则、材料和机关；地区只是换皮加专属机制。
5. **美术需求**：一个主题资产（地形图案、背景、生态）、本地区的植物与小动物、怪物、收件人、专属机关，全部走确认流程。
6. **机制来自当地的东西**：专属机制尽量取自这个文化真实的建筑、手艺、自然或民间故事（济州的跳板游戏 → 跷跷板，北欧巨魔见光变石头 → 阳光石化，荷兰的风车排水 → 风车泵），让玩家玩着玩着就记住了它。
7. **每个地区一组提示动物（只在配送模式）**：一只地上走的主动物（喂零食会说出这一步怎么做）和一只飞的（只带路），都待在下一步要用的东西旁边；规则见 [delivery-puzzle-rules.md](delivery-puzzle-rules.md) 第 5 节，清单在 `worlds.json` 的 `hint_fauna`。提示动物不当随机生态（`ambient_exclude`），外形不能像本地区的怪物。

   | 地区 | 提示动物 |
   |---|---|
   | 幽暗石牢 | 牢猫（主，零食是小鱼饼干）：蹲在下一步要用的东西旁边，尾巴指着它；蝙蝠：倒挂在下一步要去的地方的天花板上 |
   | 地府·酆都 | 小白狗（主，零食是桂花糕）：趴在下一步要用的东西旁边；彼岸蝶：停在下一步要去的地方 |
   | 黄金神庙 | 圣甲虫：推着粪球朝下一个要推的箱子滚过去 |
   | 幽光晶窟 | 飞蛾：绕着下一步要用的东西飞，像绕着灯 |
   | 迷雾古森 | 小鸟：停在下一步要去的树枝或箱子上，啄两下 |
   | 云端圣域 | 鸽子：落在下一步要踩的云块上，咕咕叫 |
   | 深空星站 | 小无人机：飞到下一步要用的东西上方，打一圈光 |

   后 5 个地区现在只是设想（各一只，用的是已有的生态动物）；做进配送 v2 时补齐主 / 飞两只，并把它们从这个地区的随机生态里关掉。

### 2.1 取材于世界各地文化的原则

1. **取材于民间故事、节日、建筑、手艺和自然**，不取材于仍被信奉的神佛本身：不把菩萨、印度教神祇等画成可推、可炸、可收货的角色；寺庙、清真寺、教堂、神社正殿只作远景或不出现。
2. **民间传说里的形象可以可爱化**（阎王、孟婆、黑白无常、河童、巨魔、雅加婆婆、蜘蛛阿南西），因为它们在当地的流行文化里也常这样出现；但不丑化，不表现血腥和刑罚。
3. **不用刻板印象**：不画"耍蛇人""草裙土著""羽毛头饰"之类的套路形象；服饰和纹样取自具体的地区和民族，不混成笼统的"异域风"。
4. **圣物和仪式不当作障碍、武器或笑料**：蒙古的敖包、澳大利亚原住民的点画、毛利人的面纹、北美原住民的羽冠一律不用。
5. **写清出处**：每个文化地区在 `inspiration` 里写取材来源，在 `care` 里写要避开的东西；美术确认时一起给用户看。有条件时请来自这个文化的玩家看一眼。
6. **名字意译**：中文用当地意思意译（地府、海女、套娃），不用音译拼写。
7. **地区之间可以对照**：水墨江南 ↔ 威尼斯水城（东西方水城），地府 ↔ 亡灵节小镇（两种怀念先人的方式），奈何桥 ↔ 安第斯绳桥（两座承重桥）。

### 3.2 地府·酆都（中国风，第 2 层）

> **v2（2026-10-16）**：配送 v2 的地府地图 `diyu_1` 已经做出来，见 [delivery-diyu.md](delivery-diyu.md)（13 间房、5 位收件人、3 种怪物、小白狗 + 彼岸蝶）。画风按用户反馈改为**荒郊野岭**（荒山、枯树、坟包、招魂幡、夜雾、鬼火、引魂灯、彼岸花），不画城墙、城楼。下面的房间表是早期设想，v2 的房间以 delivery-diyu.md 为准；故事和收件人设定仍然适用。

**故事**：阳间的人在清明、中元给逝去的亲人捎东西；渡界人负责把家书、青团、纸扎送到地府的亲人手里。地府也有自己的日常：孟婆缺汤料，判官的毛笔秃了，黑白无常想要一盏新灯笼，阎王怕热想吃冰淇淋。基调是**热闹的阴间衙门**：诙谐、温暖，偶尔有点吓人，但不血腥。

**地图的房间**（配送模式的房间模板，按从入口到收件人的顺序）：

|---|---|---|
| 鬼门关（入口） | 城门、牛头马面两位守门人 | 要出示"路引"才放行：路引放在门前的一道小谜题里（推纸扎箱压住压板）。牛头马面是守门人，不是怪物 |
| 黄泉路 | 长长的下坡，两旁开满彼岸花 | 游魂在路上飘，被灯光照到就退开；主角的灯笈第一次真正派上用场 |
| 忘川与奈何桥 | 缓缓流动的忘川，一座石拱桥 | **承重桥**：桥一次只能承受人加一个箱子，超重就塌下一格，掉进忘川；**水流漂移**：落进忘川的木箱、纸扎、货物会被慢慢冲往下游（可以去下游捡回，货物完好度 −1，纸扎直接泡坏） |
| 孟婆亭（驿站） | 桥头的小茶亭 | 驿站：喝一碗孟婆汤回一颗心——但会"忘掉"小地图上已经走过的房间（可以不喝） |
| 望乡台 | 一座高台 | 爬上去，整张地图在小地图上亮起来（效果同"地图碎片"） |
| 酆都夜市 | 纸扎铺、灯笼街、算盘声 | **跳跳僵尸**巡街：一跳一格，直线跳向你；**屏息**：你站着不动时它看不见你，会直直跳过去。商店里的"封条"在这里画成黄符，贴上就能定住僵尸 |
| 鬼火回廊 | 虚影木板搭成的回廊 | **灯照显形**：虚影木板只有被你的灯照到时才是实的，可以站人、放箱子；灯移开，上面的东西就会掉下去。灯光半径属性在这里有用 |
| 阎罗殿（收件人之家） | 大殿、判官的案台、堆成山的生死簿 | 收件人之家本身是一道小谜题：生死簿可以当箱子推，搭成台阶才够得到案台 |

**专属机制**（都先进关卡模式实验组验证，见第 4 节）：承重桥、水流漂移、灯照显形、屏息、纸扎（很轻，会浮、会被风吹，碰火立刻烧光）。

**怪物**：小鬼（成群跟着你捡走地上的东西，能推，推进忘川会被冲走）、游魂（穿墙，怕灯光）、跳跳僵尸（屏息躲开，黄符定住，引它跳进忘川）。

**收件人与缘分组合**（清单见 `recipients.json`、`combos.json`）：

| 收件人 | 规则 | 喜欢 | 缘分组合 |
|---|---|---|---|
| 孟婆 | 汤亭在奈何桥头，要先过承重桥 | 热汤、胡萝卜 | 热汤：孟婆把配方抄走，以后孟婆亭的汤回两颗心 |
| 判官 | 完好度不满会被"记一笔"，小费减半 | 文房四宝、信件 | — |
| 黑白无常 | 两人分头巡夜：货物要分成两份，分别交到两人手里 | 灯笼、纸扎小楼 | 灯笼：两人提着灯笼替你开路，下一个房间的游魂全部退散 |
| 阎王 | 阎罗殿外火很旺 | 冰淇淋、茶具 | 冰淇淋：化得更快；送到了赐一块免死金牌（本局倒下时复活一次） |

**新货物**：青团（放久变硬）、纸扎小楼（怕火怕水、会被风吹）、文房四宝（倒着拿会洒墨）。

**和地狱模式的区别**：地府·酆都是配送模式里的一个地区（中国的阴间，实时、有怪物、去送东西）；地狱模式"冥河加急件"是渡口冥河码头通往的地底九层，纯解谜、回合制。九层以后可以各借一种文化的冥界意象（[mode-hell.md](mode-hell.md)），其中一层可以是地府的"十殿"，但谜题规则不变。

**美术要点**：荒郊野岭的夜色（2026-10-16 改）：暗色的荒山、泥土和枯草，夜雾冷灰，鬼火用冷蓝；不画城墙、城楼和砖石。引魂灯是小小的暖光；彼岸花是唯一的大面积亮红；纸扎用米白和淡彩，一看就知道是纸；人物都是 Q 版，牛头马面、黑白无常的帽子和高帽上的字（白无常"一见生财"、黑无常"天下太平"）是辨认点。

### 3.3 其他新的文化地区（第 2 层）

每个地区一段：取材、专属机制怎么玩、怪物和收件人的亮点。完整字段见 `worlds.json`（含 `care` 注意事项）。

- **稻荷狐町（日本）**：雨中山道上成排的朱红鸟居，狐狸新娘只在太阳雨时出现。**翻转墙**取自忍者机关屋：推一面墙板，它转半圈，把你或箱子送到墙的另一侧。温泉会化开冰块。河童守在水边拖走东西——对它鞠躬（面对它站着不动一会儿），它也鞠躬，头顶碟子里的水洒了就没力气，可以推开（取自河童的民间故事）。
- **济州海女村（韩国）**：配送地图 `jeju_1` 已有设计稿，见 [delivery-jeju.md](delivery-jeju.md)（DSN-01）。济州自称「三多岛」——风多、石头多、海女多，三样都进了地图：白天的海边，黑色玄武岩石墙（돌담）和礁石、码头栈道、橘园台地、油菜花，远处是汉拿山。**跷跷板**取自韩国节日里女孩们站着玩的跳板（널뛰기）：一端落下重物，另一端的东西被弹起几格。济州风大，**阵风**每走一步把风里的木箱吹动一格，铁箱吹不动。小鬼怪（도깨비，可爱、一只圆头小角、拿방망이）拦路要和你摔跤，把它推出两格就算你赢；海鸥从天上俯冲叼零食，躲到石墙檐下或打伞。收件人是海女奶奶、橘园阿姨、灯塔大叔和鬼怪大王；提示动物是济州小马（喂小米糕）和红蜻蜓。石头爷爷（돌하르방）只当地标。
- **季风阶梯井（印度）**：层层下沉的阶梯井是天然的连通器关卡。**季风雨**定时下雨，井里的水位一层层上涨，台阶被淹，浮箱跟着升起。**彩粉**（第 4 层）像沙一样落下，沾到隐形的东西就让它现形。排灯节姐妹要在天黑前收到灯笼。
- **水上市场（泰国、越南、印尼）**：小船是移动平台，河水有流向（**水流漂移**），巴厘岛式梯田一层层灌满再往下溢。船娘的小船一直在漂，要追上她；榴莲很臭，怪物都追着味道来。
- **泥城鼓市（西非）**：赭色泥砖房，每年雨季后全城一起重新抹泥。**泥砖**沾水变成泥，可以挖开，也会塌；**鼓点**让平台和门按拍子动。白蚁会啃掉木箱。蜘蛛阿南西（加纳阿坎人的故事里，他从天神那里买下了所有故事）只收故事匣。
- **峡湾巨魔谷（北欧）**：巨魔力气大，会把箱子推回来；**阳光石化**：把它引到阳光下，它就变成一块能推的大石头，可以拿来压怪、垫脚。巨魔奶奶怕光，只在夜里或山洞里收货。
- **爱琴迷宫（希腊）**：美杜莎石像的**凝视**是一条直线，进入视线的怪物变成石头，人会被定住；用镜子把视线反射回去。牛头怪直线冲撞，引它撞墙。西西弗斯一辈子在推石头上山，是最懂推箱子的收件人；给他送保险箱，他会说"这个我熟"。
- **威尼斯水城（意大利）**：和水墨江南是一对东西方水城。冬天涨潮（潮汐），贡多拉是移动平台，运河有流向。玻璃匠只看易碎品的完好度。
- **风车堤坝（荷兰）**：**风车泵**把低处的水抽到高处，让圩田变干；麝鼠在堤坝里打洞，打穿就漏水，要用石头或沙袋堵住。冬天运河结冰，可以滑行。
- **雅加婆婆的森林（斯拉夫）**：**套娃箱**被炸、被烧、被酸蚀时掉出一个小一号的箱子，最多三层。雅加婆婆的鸡腿小屋会走，要对它说"小屋小屋，背对森林，面对我"才会转过来开门（俄罗斯童话里的原话）。林精会让你迷路，原地转一圈就能破解（民间说法是把衣服反穿）。
- **雨林天然井（玛雅）**：石灰岩地面会塌陷（碎石），露出下面的天然井；春分秋分时台阶上出现光影羽蛇（昼夜机制）。可可豆古时当钱用，可以在驿站付账，但每付一次完好度 −1。
- **亡灵节小镇（墨西哥）**：亡灵节是纪念家人的温暖节日，不是万圣节。**花瓣引路**：撒下的万寿菊花瓣连成一条路，亡魂和一些怪物会沿着花瓣走，可以用来引开它们。曾祖母只在节日的夜里回家，要沿着花瓣路找到她。和地府是一对：两种怀念先人的方式。
- **安第斯绳桥（秘鲁）**：凯斯瓦恰卡绳桥是**承重桥**（和奈何桥同一个机制，换一身美术）；**驮兽**：把大件放到羊驼背上，它按自己的路线慢慢走到对面。
- **西部小镇（美国西部）**：**矿车**沿轨道一直滚到撞上东西为止，可以载人或载货；风滚草被阵风吹着滚，碰火就烧。响尾蛇靠近会先摇尾警告。

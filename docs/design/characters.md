# 角色：主角、收件人与渡口居民（设计稿）

状态：设计稿。主角美术候选已在工作台（`char.portitor`，待确认）。收件人、怪物清单以 `content/catalog/recipients.json`、`monsters.json` 为准。总纲见 [vision.md](vision.md)。

## 1 主角：摆渡人

### 1.1 设计要求

1. **不是传统快递员**：不要制服、鸭舌帽、快递箱。
2. **放进任何世界都不违和**：水墨江南、奇幻仙境、外星港口、墓园都要站得住。
3. **16×16 也认得出**：靠轮廓，而不是靠细节。
4. **养成看得见**：背包格数、灯光半径这些属性最好直接画在角色身上。

### 1.2 方案 A（推荐）：斗笠灯笈

| 部件 | 设计 | 作用 |
|---|---|---|
| 宽檐斗笠 | 草黄色，比身体还宽，帽檐压住脸 | 轮廓的第一识别点；东方气质 |
| 两点亮眼 | 斗笠下只露出一对暖黄色的眼睛 | 神秘：没人知道斗笠下是什么，所以它在哪个世界都合适 |
| 红围巾 | 长长一条，跑动时向后飘 | 动态和朝向一眼看清；全身唯一的红色 |
| 深紫斗篷 | 罩住全身 | 紫色在六个已有主题中都不撞色 |
| 箱笈 | 背上一只比头还高的木箱，有一排小抽屉 | 呼应"背箱子的人"（拉丁语 *capsarius*）；**抽屉数 = 背包格数** |
| 小灯 | 挂在箱笈顶上的一盏小灯 | 摆渡人的灯；**灯光大小 = 黑暗地区的视野** |
| 篙铲 | 一根细杆，一头是桨叶 | 既是撑船的篙，也是挖土的铲 |

动作上的小设计：倒沙时拉开一只抽屉，沙从抽屉里倒出来；爬梯时从背后看，看到的是箱笈和小灯；胜利时举起小灯。

色板：斗笠 `k d F`，斗篷 `B C`，围巾 `i h`，箱笈 `e f g`，灯 `l k`，眼睛 `l`，靴子 `z y`（ENDESGA 32）。

### 1.3 备选方向（只做了概念，用于比较）

| 方向 | 样子 | 优点 | 缺点 |
|---|---|---|---|
| B 铜铃机偶 | 铃铛形脑袋的发条小机器人，背上一把发条钥匙 | 跨世界、科幻感，动作可以很机械很可爱 | 偏冷，东方地区不够贴 |
| C 狐面行者 | 戴狐狸面具的旅人，背一只竹编书箱 | 东方味道很浓，神秘 | 在外星港、僵尸镇里不够中性 |

### 1.4 动作清单

第 0 层（关卡模式）沿用现有 8 组动作：待机、走、推、爬、挖、倒、落、胜利，共 21 帧。

配送模式再加（第 1 层）：拿小件、抬大件（举过头顶、走得慢）、受伤、倒下、在冰上滑、游泳、在渡口坐着。

### 1.5 旧的矿工

已确认的 `char.miner` 不浪费：建议改做收件人"老矿工"（幽暗石牢），或者训练场的教官。

## 2 收件人

### 2.1 设计规则

- 收件人是滚轮上的另一半。每位收件人有**家乡地区**（可以有多个，先用已开放的地区）、**稀有度**、**脾气**（影响评分）、**收件小规矩**（让最后一个房间不一样）、**喜欢的货物**（缘分组合）。
- 外形要有强烈的剪影：小孩、老人、大象、妖精、外星人、僵尸……放在滚轮的小格子里也能一眼认出。
- 每位收件人至少要有：滚轮头像（24×24）、站立、开心收货的动画。

### 2.2 第 1 层的 12 位（你举的例子都在里面）

| 收件人 | 去哪里 | 脾气与规矩 | 喜欢 |
|---|---|---|---|
| 小孩 | 乡村小路 | 急性子：用时最影响小费 | 气球花束、糖 |
| 老奶奶 | 乡村小路 | 慢性子：只在乎完好；住三楼，楼里有货梯 | 钢琴、毛线、热汤 |
| 大象 | 黄金神庙（以后去草原象谷） | 收大件；好感高时用鼻子喷水帮你灭火 | 花生、西瓜 |
| 法老猫 | 黄金神庙 | 傲娇：小费随心情浮动 | 鱼 |
| 妖精 | 迷雾古森（以后去奇幻仙境） | 很小，家门只有半格高 | 鲜花、蜂蜜 |
| 树人爷爷 | 迷雾古森 | 走得极慢，要等他转过身 | 盆栽、浇水 |
| 外星人 | 深空星站（以后去星际港） | 门牌是外星文字，要对照图鉴找家 | 外星蛋、地球土 |
| 星站工程师 | 深空星站 | 准时最重要 | 热汤、家书 |

| 老矿工 | 幽暗石牢 | 旧主角改做的收件人 | 头灯、三明治 |

第 2 层以后的收件人（幽灵、吸血鬼伯爵、龙王、美人鱼、书生、仙人、熊猫、雪人、神灯精灵、恐龙宝宝、嫦娥、玉兔、海盗船长等）见 `recipients.json`。

### 2.3 收件人好感

同一位收件人送得越多、评级越高，好感越高。好感解锁：感谢信与小故事 → 谢礼（渡口装饰）→ 专属缘分组合 → 在地图上出手帮忙一次。

## 1 一句话

你是**渡界人**（PORTITOR）——万界渡口的送货人。滚轮一转，决定这一单送什么、送给谁：一支冰淇淋送给火精灵，一封情书送给僵尸，一架钢琴送给大象。推箱、攀爬、挖土、倒沙、放炸药，利用会流动、会燃烧、会结冰的真实材料（ele-base-cpp SDK 模拟），穿过水墨江南、奇幻仙境、乡村小路、外星港口……把东西亲手交到收件人手里。

## 2 世界观：万界渡口

- 在无数世界的交汇处，漂着一座小小的**渡口**。渡口里有许多扇**渡门**，每扇门通往一个世界：中国风的水墨小镇、童话般的仙境、麦田边的乡村小路、闹鬼的墓园、外星殖民港、海底龙宫……
- **渡界人（Portitor）**是渡口的送货人，什么都送，送给谁都行：小孩、老人、大象、妖精、外星人、僵尸、龙王、雪人……拉丁语 *portitor* 是搬运者、摆渡人，维吉尔也用这个词称呼冥河渡夫卡戎，所以地狱模式就是"冥河加急件"。
- 每送成一单，收件人会寄来谢礼和感谢信。谢礼会摆进渡口，渡口慢慢变热闹，也会打开新的渡门。
- 题材自由融合：东方的斗笠和灯笼、西方的童话和骑士、科幻的外星人、恐怖片的僵尸，可以出现在同一个渡口里。每个世界内部保持统一风格，世界之间可以差异很大。
- **世界各地的文化**（2026-10-15 用户要求）：地区取材于各民族的民间故事、节日、建筑和手艺——中国的地府、日本的狐町、韩国的海女村、印度的阶梯井、西非的泥城、北欧的巨魔、希腊的迷宫、墨西哥的亡灵节……专属机制也来自当地真实的东西。取材原则和清单见 [worlds.md](worlds.md) 第 2.1、3 节。

## 3 三个模式与优先级

开发顺序：**关卡模式 → 配送模式 → 地狱模式**（2026-10-15 用户决定；用户原话中的"闯关"即配送模式）。

| | 关卡模式 | 配送模式（核心） | 地狱模式 |
|---|---|---|---|
| 在故事里 | 渡口训练场：每块场地练一个机制 | 接单出门，跨世界送货 | 冥河加急件：送往地底九层 |
| 玩法 | 每关只演示一个机制，地图很简单；也是新机制的试验场和 SDK 回归测试 | 双滚轮决定货物和收件人；穿过多个房间拼成的地图；怪物、事件、商店；连送 | 纯推箱解谜，难度高，不给提示，允许多解 |
| 时间 | 回合制（动作 → 结算 → 再操作） | **按格移动 + 实时世界**：每走一格有一小段移动间隔，世界持续运转，可随时暂停 | 回合制 |
| 随机性 | 无 | 有 | 无 |
| 局外养成 | 不受影响 | 受影响（有上限） | 只发奖励，难度不受影响 |
| 状态 | **现在做** | 设计稿，关卡模式完成后开工 | 设计稿，最后做 |

**配送模式的时间**（2026-10-15 用户确定）：人物仍然按格移动，两步之间有一小段"移动间隔"，**移动速度就是缩短这个间隔**；怪物、水流、火、货物计时在实时运转，可以随时暂停。按格移动的实时玩法有成熟先例：《Boulder Dash》按格挖掘、落石会压扁敌人、要在时限内收集钻石；《炸弹人》按格移动，加速鞋是经典道具。关卡模式和地狱模式保持回合制，专心解谜。详见 [mode-delivery.md](mode-delivery.md) 第 4 节。

## 4 内容一层一层加

先把每层做完整、做好玩，再加下一层。所有新机制都先进关卡模式的实验组验证（[game-design.md](game-design.md) 6.7）。

| 层 | 内容 | 依赖 |
|---|---|---|
| 第 0 层（现在） | 关卡模式：第一批是第 1、2 组共 16 关（SDK 的沙与水 + 开关、升降台、收集斗、承重桥、传送阵）；第 3–5 组是融合章概念卡（爆破 + 矿车、灯照显形、套娃箱；酸与气体 + 弹跳蘑菇、跷跷板；冷热 + 冰面滑行、阵风）；全套菜单 | — |
| 第 1 层 | 配送模式最小可玩：双滚轮（12 种货物 × 12 位收件人）、6 个已有主题作为地区、按格移动 + 实时世界、生命与货物完好度、金币与商店、背包、5 项属性养成、推怪与压怪 | 第 0 层 |
| 第 2 层 | 新地区（乡村小路、水墨江南、奇幻仙境、墓园鬼镇、星际港等）和它们的专属机制、怪物扩充、随机事件、顺路单、连送、徽章、收件人好感、加急令 | 第 1 层；每个新机制先过实验组 |

| 第 4 层 | 新 SDK 机制（电、气压、粒子、刚体）、更多地区与收件人、节日活动、第三个滚轮（委托条件） | SDK 扩展 |

## 5 主角

主角不是传统的快递员，而是一个**跨世界的渡界人**：宽檐斗笠遮住脸，只露出两点亮眼；背着一只带抽屉的木箱笈，箱顶挂着一盏小灯；红围巾；手里的篙铲既能撑船、也能挖土。抽屉的数量就是背包格数，灯照亮黑暗地区，这些养成都直接画在角色身上。完整设计和动作清单见 [characters.md](characters.md)。美术 `char.portitor` 已由用户确认（`APR-0003`），所有场景和界面已换成新主角。

## 7 已经决定（2026-10-15）

1. **名称**：《渡界人》· PORTITOR（[naming.md](naming.md)）。

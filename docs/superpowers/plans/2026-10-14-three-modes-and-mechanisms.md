## 3. 第二阶段 A 详细执行清单（零改 C++ 引擎 · 6 大地图 36 关有解关卡池 + 满 3 关解锁）

> **核心原则**：本阶段**绝不修改或重编 `ele-base-cpp` C++ 动态库**（`bin/` 下 7 个二进制与 `ele.gdextension` 保持 SHA-256 100% 不变），全部利用现有 SDK v1.2.0 能力与 GDScript 游戏层确定性规则实现，先做出完整可玩的 6 大地图关卡池供外部玩家试玩。

### 任务 2A.1：扩展现有 JSON 内容与游戏层零改引擎独特机制（`board.gd` / `session.gd`）
**规格文档**：[`docs/mode-and-level-design.md`](../../mode-and-level-design.md) 第 0 节实现表、第 2.1–2.6 节关卡设计
- [x] **2A.1.1 接入 SDK 现有材质与反应配置（`content/default/` & `rules.json`）**：
  - 在 `materials.json` 新增 `iron_crate`（沉水铁箱占位）、`acid`（强酸液体）、`fume`（短寿命酸雾）、`lava`（发光熔岩）、`pumice`（高密度浮石沙，`density: 90`）、`ice`（实心可爆破冰层）。
  - 在 `reactions.json` 配置 `acid + cracked_rock -> fume + empty` 与 `water + lava -> pumice + pumice`。
  - 在 `rules.json` 配置 `box_kinds.iron`（`floats: false`）与 `pour.order: ["pumice", "sand"]`（保持 D1–D5 与 T01–T04 原有行为与哈希零回归）。
- [x] **2A.1.2 在游戏层（`board.gd`）实现 6 大地图的零改引擎独特机关**：
  - **地牢独特机关（千斤防夹闸 + 矿柱塌方）**：直接复用现有 `gate.crush_max` 与裂岩爆破坍塌。
  - **森林独特机关（吸水生长藤梯 `vine_seeds`）**：在 `resolve_round()` 中，当 `vine_seed` 格或其四邻格含水（`WATER`）时，自动将其上方指定高度的连续格加入动态 `ladders`（玩家与视觉层立即可作为藤梯攀爬）。
  - **遗迹独特机关（流沙计时漏斗 `hourglasses` + 双盘配重天平 `scales`）**：流沙漏斗支持按 `moves_gt` 或拉杆自动开启顶部沙闸定量漏沙；配重天平通过比较左盘区域的总重量（铁箱=2、木箱=1、满格沙=1）自动升降右盘托台（将右盘上的箱子与人物同步托高或降下）。
  - **洞穴独特机关（钟乳石震落重锤 `stalactites` + 定量间歇泉 `geysers`）**：钟乳石在顶部支撑裂岩被炸毁/酸蚀后，作为不可推动的重物岩块直落到底（砸毁正下方 `ice`/`cracked_rock` 并沉底筑坝）；间歇泉每 $N$ 回合在未受箱体镇压时向喷口格注入 1 格水/酸液。
  - **天空岛独特机关（急冻冰桥切换 + 浮云弹性软垫 `cloud_pads` + 定向顺风场 `wind_zones`）**：冷冻拉杆触发时将连通水体顶层转化为实心 `ice`（解冻时还原为 `water`）；`cloud_pads` 格在 `_supported()` 中仅支撑 `wood` 木箱与人物，`iron` 铁箱推上后直接穿透下坠；`wind_zones` 开启时，倒出的云沙落点向风向顺延 1 格，冰面上的箱子顺风多滑行 1 格。
  - **宇宙独特机关（量子物质传送座 `teleporters` + 舱段反重力 `gravity_zones`）**：`resolve_round()` 中进入发射座 `TP_A` 的箱子或松散沙格（且接收座 `TP_B` 为空）自动瞬移至 `TP_B`；`gravity_zones` 激活反重力时，舱内无磁锁的 `wood` 箱与松散沙粒向舱顶方向坠落/上浮，而带电磁底盘的 `iron` 箱保持锁定在底部磁轨。

### 任务 2A.2：实现「6 大地图关卡池 + 观察池 + 通关 3 关解锁下一地图」UI 与存档系统
**涉及文件**：`pushbox/scripts/ui/lobby_view.gd`、`pushbox/scripts/ui/biome_showcase_view.gd`、`pushbox/scripts/game.gd`
- [x] **2A.2.1 地图逐步解锁规则（3-to-Unlock Map Progression）**：
  - 闯关模式按顺序组织 6 张主题地图：`0.幽暗石牢(dungeon)` → `1.迷雾古森(forest)` → `2.黄金神庙(ruins)` → `3.幽光晶窟(cave)` → `4.云端圣域(sky_island)` → `5.深空星站(cosmos)`。
  - 初始默认解锁**地图 1（幽暗石牢）**；每张地图拥有独立的 **6 关关卡池**。
  - **跨地图解锁门槛**：只要在当前地图的 6 关池中**累计通关满 3 关（`completed_in_map >= 3`）**，立即自动解锁下一张风格地图！
  - **池内滑动开放防卡关**：每张地图解锁时默认开放前 2 关（★入门关）；在该图每多通关 1 关，额外开放池内后续 2 关（★★进阶关与★★★大师大图关），让玩家永远有多个备选关卡可挑，绝不因单关卡壳而无法推进。
  - **双档徽章激励**：通关满 3/6 关点亮该地图的「通行银章」，通关满 6/6 关点亮「全清金冠」；6 张地图全部达到 3/6 通行后解锁主线通关横幅与第三阶段挑战模式入口。
- [x] **2A.2.2 观察池（Observation Pool / 地图侦察模式）融合**：
  - 在每个地图池界面提供**「进入观察池（侦察全景）」**切换开关（复用并升级阶段 1.5 的 `biome_showcase_view.gd`）：玩家在正式解题前或卡关时，可以随时切入观察池无压力浏览该地图全部关卡（包括尚未解锁的高星大地图）的完整地形、水路与独特机关分布。

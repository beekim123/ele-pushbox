## 2. 第一阶段详细执行清单（当前交给 GPT 立即执行）

### 全局硬约束（GPT 必读）
1. **单 worker 顺序执行**：测试全程单 worker、`EleWorld.threads = 1`，跑测试前先确认无残留 Godot/Python 进程。
2. **D1–D5 规则与哈希零回归**：`board.gd`、`session.gd`、`rules.json` 的物理结算逻辑不动；现有 14 个常规测试脚本与 1 个 T8 性能脚本（结算峰值 `<= 4 ms`，预演延迟 `<= 100 ms`）必须全部通过。
3. **零新增操作按键**：保留 `WASD`/方向键、左键挖、右键倒、拖炸药、`↑`/点击拉杆、`Z` 撤销、`R` 重开、`Esc` 菜单。

### 任务 1.1：美术全量改为纯代码生成（摆脱 `.png` 贴图文件）
**涉及文件**：`pushbox/scripts/ui/pixel_style.gd`（或新增 `pushbox/scripts/ui/procedural_art.gd`）、`pushbox/scripts/render/world.gdshader`、`pushbox/scripts/game.gd`
- [x] **1.1.1 精灵与 UI 纯代码生成**：
  - 将原 `tools/reference_art.py` 中的所有精灵（`miner_*` 各动作帧、`crate_static_0`、`ladder_static_0`、`target_*`、`lever_*`、`plate_*`、`gate_closed_0`、`lantern_*`、`keycap_*`、`mouse_*`、`hand`、`icon_bomb`、`icon_sandbag_0..7`、`cursor_shovel`、`panel_9slice`、`icon_lock`）及大厅模式卡片图标改为在 GDScript 中由代码直接构造 `Image` 并通过 `ImageTexture.create_from_image()` 缓存在 `Style._textures` 字典中。
  - `Style.texture(name)` 对外接口、图像尺寸（`16×16` 等）、颜色（ENDESGA 32 调色板）与不透明像素分布保持与原图一致（确保 `tests/bugfix.gd` 中的人物朝左逐像素镜像检查与 `tests/v03_render.gd` 中的白色像素检查直接通过）。
  - `Style.warm_assets()` 直接在内存中构建全部代码贴图，不再读取 `res://pushbox/assets/sprites/*.png` 文件。
- [x] **1.1.2 地形纯 Shader 代码渲染**：
  - 在 `world.gdshader` 中将 `bedrock`（16×16 基岩砌块与受光边）和 `cracked_rock`（裂岩底色与深色裂纹）也改为纯 Shader 数学/哈希函数生成（与现有的纯代码 `sand`、`water` 一致），不再依赖外部采样贴图 `bedrock_tex` / `cracked_tex`。
- [x] **1.1.3 验证纯代码美术基线**：
  - 运行 `python3 tools/run_tests.py --performance`，确认在不加载任何 `.png` 文件的情况下，14/14 常规测试、40 项 `bugfix.gd` 专项测试及 T8 性能测试 100% 通过。

### 任务 1.2：实现纯代码像素「主界面大厅 UI（Lobby UI）」与选关流转
**涉及文件**：新增 `pushbox/scripts/ui/lobby_view.gd`，修改 `pushbox/scripts/game.gd`、`pushbox/scripts/ui/pause_menu.gd`
- [x] **1.2.1 主大厅画面与三模式卡片（按 `docs/mode-and-level-design.md` 第 2 节规格）**：
  - 在 `320×180` 逻辑画布（随窗口整数缩放居中）上用纯代码绘制主大厅：顶部标题《推箱子：沙与水》与闪烁挂灯、中部三张 `88×92` 像素九宫格模式卡片（**教学模式**显示 `已通 X/4 关`；**闯关模式**与**挑战模式**显示 `icon_lock` 锁头图标与阶段提示）、底部操作提示。
  - 支持方向键/`WASD` + `Enter` 或鼠标悬停/左键点击选择模式卡片。
- [x] **1.2.2 二级选关面板与局内菜单联动**：
  - 点击「教学模式」卡片展开选关面板（列出 `T01–T04` 及已通关金色标记，支持返回大厅）。
  - 局内 `Esc` 暂停菜单增加 `返回大厅` 项；通关 `T04` 后自动返回大厅并更新进度存档（`user://progress.json`）。
  - **测试兼容规则**：当自动化测试通过脚本直接调用 `game.select_level(...)` 或在无大厅参数下运行旧测试时，保持原有直入关卡行为，确保旧测试脚本零改动通过。

### 任务 1.3：优先制作第一部分「教学模式」（`T01–T04` 共 4 个简单关卡）
**涉及文件**：新增 `pushbox/levels/tutorial/t01.json`–`t04.json`，新增 `tests/tutorial_stage1.gd`
- [x] **1.3.1 制作 4 个极简教学关（按 `docs/mode-and-level-design.md` 第 4 节规格）**：
  - **`T01`《移动与推箱》**：覆盖方向键移动、1 格自动登台阶、爬梯子（`↑`/`↓`）、推箱入坑，以及墙面提示 `Z` 撤销 / `R` 重开（`10×6` 格，8 步过关）。
  - **`T02`《挖沙与造坡》**：覆盖鼠标悬停预演、左键点击相邻沙格挖入沙袋（`DIG_`）、右键点击相邻格倒沙（`POUR_`）自然坍塌成 45° 台阶登高推箱（`10×6` 格）。
  - **`T03`《放水与浮箱》**：覆盖走近拉杆按 `↑`（或左键点拉杆）放水、U 形连通器水位拉平托起木箱，以及向左侧带沉沙囊的水道倒沙挤高水位把木箱顶出井口（`11×8` 格）。
  - **`T04`《机关与爆破》**：覆盖推箱踩压板开门、踩受阻箱翻越障碍，以及从右上角拖拽炸药图标到裂岩旁松手十字爆破（`12×5` 格）。
- [x] **1.3.2 编写并跑通 `tests/tutorial_stage1.gd`**：
  - 验证大厅 UI 打开/选模式/选关流转，`T01–T04` 的作者解法回放（T1）、撤销重做（T5）、悬停预演一致性（T6）、关内引导（`guides`）触发与消失，以及导出大厅 UI 与 `T01–T04` 实机截图。
  - 完成后在本文件将 `1.1`、`1.2`、`1.3` 全部勾选为 `[x]`，并更新 `docs/v2/status.md`，停下交由设计侧审核。

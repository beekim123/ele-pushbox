2. build 初次音源生成 v1，同一内容重建 0 bumped/0 changed；hash 包含源中所有影响声音的数据与渲染器。按 audio.md 第 4.2 节支持锁定 Git 发布基线：新音源多次改源始终 v1，已发布音源多次改源始终基线+1，不覆盖已确认同版本不同 hash；过期/不存在基线必须失败。保存当前 preview、manifest、工作台 audio.js；`--kind` 不修改另一类的源版本或移除其导出。没有源文件允许 build 干净完成、清楚列出未制作项，不能生成假静音候选。按规范创建空 audio/approvals.json（records:[]），仅首次不存在时创建；已有记录不得清空或重排。

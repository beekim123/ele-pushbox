# UI-02 界面方案比较台 + 方向 A 样稿

状态：等 UI-01 通过后开始
设计依据：UI-01 报告 `docs/research/2026-10-ui-style.md`（方向 A、样稿界面清单）；[美术流程](../design/art-pipeline.md) 第 2 节（新界面不碰已确认文件的做法）

## 目标
1. 做一个**界面方案比较台**：同一组样稿界面（默认 lobby、levels、pause、settlement，以 UI-01 为准），可以换不同的"皮肤"（面板、按钮、图标、字号、配色、装饰）来画，中英文都画；工作台里能把现有样式和各方案并排看。
2. 用比较台做出**方向 A** 的样稿。UI-03、UI-04 只需要加自己的皮肤，不再改比较台。

## 要读的文件
- AGENTS.md；`docs/research/2026-10-ui-style.md`；`docs/design/art-direction.md`、`docs/design/art-pipeline.md`
- `workbench/js/core/ui.js`、`ui-delivery.js`（现在的布局，样稿的内容和文字应与之一致，便于比较）；`tools/art.mjs`（loadCore 列表、参考图怎么出）；`workbench/index.html`；`workbench/js/app/views/scenes.js`（场景页怎么展示）

## 要产出的文件
- 新的绘制文件，例如 `workbench/js/core/ui-options.js`：样稿界面的画法 + 皮肤接口（皮肤是数据或一个对象：九宫格、按钮三态、图标、颜色、字号倍数……）。**不改 ui.js / ui-delivery.js**。
- 方向 A 的皮肤精灵：`art/source/ui-option/ui.option_a.*.json`（新文件，`stage: "draft"`——方案阶段不走确认，选定后再在 UI-05 正式做）。
- 若样稿需要新文字，放新表 `content/i18n-uioptions/`，缺字形用 `python3 tools/build-font.py --ext uioptions`。
- 工作台展示：在「场景」页加一组"界面方案"（或新页面），每张样稿界面一行：现有样式 | 方向 A |（之后 B、C），可切中英文。
- 比较图：`node tools/art.mjs build` 能导出的话就放 `art/export/reference/` 之外的地方，例如新增 `art/export/options/<方案>.<界面>.<语言>.png`；或者写一个小脚本 `tools/ui-options.mjs` 导出。用户要能直接打开 PNG 看。
- 本包「交付」一节写明：皮肤接口怎么加一个新方向（给 UI-03 / UI-04 用）。

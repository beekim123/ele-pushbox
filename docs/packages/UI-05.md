# UI-05 按选定方向重做全部界面美术（工作台）

状态：界面线第 4 步 · 待做（分支 `ui/redo-html`；需要 [UI-CHOICE](UI-CHOICE.md) 已填写；只改 HTML 工作台，不碰 `game/`）
设计依据：[界面风格定稿](../design/ui-style.md)（取代 UI-01 报告里的方向）；UI-CHOICE 里用户的补充意见；UI-02–04 的比较台与选定方向的皮肤；[美术规范](../design/art-direction.md)；[美术流程](../design/art-pipeline.md)

## 目标
把工作台里全部界面换成选定的方向：界面精灵、15 个界面布局（关卡模式 9 个、配送 6 个）、关卡 HUD、配送 HUD。做完后这些资产生成新版本、回到待确认，由用户在工作台确认；确认后由 UI-06 同步到项目。

## 这次允许改的冻结区文件（用户 2026-10-16 要求重做界面）
- `art/source/ui/*.json`（界面精灵：面板、按键、图标、菜单图标、光标、气泡、表情、目标灯、配送 HUD 图标等，按方向需要改）
- `art/source/screen/*.json`（界面资产的 `params` / `renderer` / `depends`，按需要）
- `workbench/js/core/ui.js`、`workbench/js/core/ui-delivery.js`（界面画法），`workbench/js/core/scene.js` 里的 `drawHud`（只改 HUD，不改关卡画法）
- 界面文字原则上不改；确实需要新文字时放新表 `content/i18n-ui/`，缺字形用 `python3 tools/build-font.py --ext ui`

## 不能碰的文件
- 其他冻结区：角色、物件、机关、特效、主题、材料的源数据；`art/approvals.json`、`art/history/**`、`art/export/approved/**`（工具自动写的除外）；`font-data.js`、`font-small.js`；`content/i18n/*.json`、`content/i18n-delivery/*.json`
- 关卡、目录、`game/**`

## 验收标准
- `node tools/art.mjs build`：换版本的只能是界面精灵（`ui.*`）和界面（`ui.screen.*`），列出清单；角色、物件、机关、特效、主题、材料一项都不换版本
- `node tools/art.mjs verify` → `verify ok`（中英文排版 0 个问题、字形齐全）
- `node --test tests/*.test.mjs`、`node tests/workbench.e2e.cjs` 全部通过
- 工作台「确认」页能看到全部换了版本的界面资产
- 「交付」里写出给用户确认用的命令（版本号以 build 结果为准）：`node tools/art.mjs approve --items <id@vN,...> --by 用户 --via chat --scope "界面重做" --note "<用户原话>"`，以及每个界面改前 / 改后的对照图位置

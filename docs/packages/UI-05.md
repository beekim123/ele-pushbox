# UI-05 用选定的方向重做全部界面美术（大纲，用户选定方向后细化）

状态：等用户在 UI-02–04 的样稿里选定方向

## 目标（大纲）
- 用选定方向重做界面精灵（`ui.panel`、`ui.keycap`、`ui.icons`、`ui.menu_icons`、`ui.cursor`、`ui.bubble`、`ui.delivery_icons` 等）和 15 个界面布局、关卡 HUD、配送 HUD。
- 这会改到冻结区（`ui.js`、`ui-delivery.js`、`scene.js` 的 HUD、界面精灵），所有受影响的界面会生成新版本、回到待确认——**这是用户要求的重做，允许改的文件在细化时逐个列出**。
- 交付后由用户在工作台确认；确认后另开一个包让 Godot 端（GPT）按新参考图更新界面。

细化时由设计负责人补全：要改的文件清单、按界面拆成几个小包、验收标准。

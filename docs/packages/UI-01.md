# UI-01 界面美术调研：现状问题、参考作品、三个方向

状态：待审核

## 目标
写一份调研报告：现在的界面哪里丑、为什么丑；同类像素游戏的界面怎么做得好；提出 **三个明显不同、都可行** 的界面美术方向，让 UI-02–04 照着做样稿。只调研和写报告，**不画最终美术、不改代码**。

## 要产出的文件
- `docs/research/2026-10-ui-style.md`，包含：
  1. **现状问题清单**：逐个界面列问题（层次、对比、留白与对齐、字号、面板和按钮样式、图标风格是否统一、关卡模式与配送界面是否像同一个游戏、与主题背景的关系、中英文排版）。每条写清"哪里、为什么不好"，按严重程度排序。
  2. **参考**：8–12 个分辨率和风格相近、界面口碑好的像素游戏（每个写：值得学的一两点、截图或资料链接）。
  3. **三个方向**（A / B / C），每个写：一句话气质、和"万界渡口 / 渡界人"世界观的关系、ENDESGA 32 里用哪几种颜色、面板与边框的造型母题、按钮三态（普通 / 选中 / 不可用）、标题与正文字号（字体只能用 Fusion Pixel 12px / 10px，可整数倍放大）、图标风格、动效原则、风险与成本。三个方向要拉开差距（例如：一个木与纸的旧渡口、一个更扁平清爽的现代像素、一个有强烈主题色的符箓 / 灯笼风），由你根据调研决定。
  4. **样稿要画哪些界面**：建议固定 4 张给三个方向共用（默认：大厅 lobby、关卡选择 levels、暂停 pause、送达结算 settlement），说明理由；若你认为换别的更能看出差别，写明替换。
- 每个方向可附 1 张粗略的示意图（可选，放 `docs/research/ui-style/`，标明"示意，不是候选美术"）。

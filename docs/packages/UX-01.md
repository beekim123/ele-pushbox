## 目标
写一份调研报告，回答三件事：
1. **问题在哪**：从第一次打开游戏到通过第 1 组（M01–M07），玩家在哪些地方会不知道怎么操作、不知道目标是什么、不知道为什么失败。
2. **别的游戏怎么做**：找同类游戏的做法，每条都要写出处。
3. **怎么改**：给出具体的改造方案，按"花的力气 / 效果"排好先后。

**只写报告，不改任何设计、代码和关卡。** 设计负责人看过报告、用户拍板后，再拆成制作包。

## 调研范围（至少覆盖）
- **同类解谜 / 推箱子**：Baba Is You、Stephen's Sausage Roll、Patrick's Parabox、A Monster's Expedition、Snakebird、Sokobond。
- **像素平台 + 挖掘 / 物理**：Celeste、Spelunky、SteamWorld Dig、Terraria、Noita、Mr. Driller。
- **公认的教学设计**：Portal、超级马里奥 1-1、Inside / Limbo。
- 关注的问题：
  - 不用文字怎么教操作；
  - 键位提示什么时候出现、什么时候消失；
  - 第一次见到的机关怎么让人看懂；
  - 卡关时提示怎么给才不剧透；
  - 失败或死局怎么让人知道"该撤销 / 重开了"；
  - 修饰键操作（Shift 挖、Ctrl 倒沙）这类不直观的键位怎么教；
  - 手柄怎么教。

## 要产出的文件
`docs/research/2026-10-17-onboarding.md`（中文，写得让不懂技术的人也能看懂），包括：
1. **现状走查**：按"打开游戏 → 大厅 → 选关 → M01 → … → M07"的顺序，每一步写清楚：
   - 玩家看到什么；
   - 系统告诉了他什么；
   - 他可能卡在哪；
   - 严重程度（高 / 中 / 低）。
2. **参考做法**：每个游戏一小段：它怎么做、为什么有效、能不能搬到我们这里；附出处链接。
3. **改造建议清单**：每条写明：
   - 改什么、改在哪一关或哪个界面；
   - 需要的新美术或新文字；
   - 要不要改关卡地图；
   - 大致工作量（小 / 中 / 大）。

   按优先级排。至少要覆盖：
   - 键位提示：画在画面里的按键图标、第一次需要时才出现；
   - 第一关的目标说明：箱子进槽、点亮目标灯；
   - 挖和倒沙的教法；
   - 死局时提醒撤销；
   - 提示按钮（H）让人知道它存在；
   - 第 1 组每关开局画面是否一眼能看出该做什么。
4. **建议的第 1 组新流程**：一张表，每关一行，写"这一关教什么、怎么教、用到哪些新提示"。
5. **要用户决定的问题**：列出几个选项，每个写好处和坏处。

## 用户的要求（2026-10-17 原话整理）
1. 现在的界面（S1 晶石琉璃）**偏向某一种固定风格，不通用**。游戏界面要重做成**通用风格**。
2. **先出几个风格，用户来选**；选定后再按这个风格做一整套（那是下一个包 [UI-10](UI-10.md)，不是这一包）。
3. **再加一个通用风格的大厅**。原来按章节换的大厅皮肤**保留**。

"通用"的意思（写给制作方）：
- 不属于任何一张地图：没有水晶、符文、玉简、泡泡这类主题装饰；
- 放在**暗的**地图（石牢、地府）和**亮的**地图（云端、以后的海女村）上都好看、字都清楚；
- 休闲、清爽、友好，像素风，和主角 `char.portitor` 放在一起不突兀；
- 以后加新地图、新模式也能直接用。

## 目标
做出 **3–4 个通用风格提案**，每个都画在**同一组样板界面**上，放在工作台的一个对比页里，让用户一眼比较、选一个。

## 每个提案要包括
1. **名字和一句话说明**：例如"白纸卡片""深色玻璃""木框便签"，这只是举例，请自己设计。
2. **组件**：
   - 面板（大、小两种）、标题条；
   - 按钮（普通、选中、不能按三态）、光标；
   - 键帽提示、滑块、开关、标签；
   - 说话泡、心里话泡；
   - HUD 底板；
   - 用到的调色（ENDESGA32 代码）。
3. **样板界面**（每个提案画同样这几张，320 × 180，中文版）：
   1. **通用大厅**：标题、主菜单（关卡模式 / 配送 / 设置 / 退出）、金币；
   2. **暂停菜单**：在一张**暗**地图上，用石牢关卡做背景；
   3. **过关 / 结算**：在一张**亮**地图上，用云端或神庙关卡做背景；
   4. **关卡 HUD**：顶部状态栏；
   5. **配送开局三滚轮台**：地图 → 收件人 → 货物，用已有的 `avatar.*`、`cargo.*` 图。
4. **英文**：每个提案再画一张英文版暂停菜单，检查英文放不放得下。

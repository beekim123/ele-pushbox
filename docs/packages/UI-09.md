## 目标
v1 旧版不要了，配送的游戏界面要换成 v2 的。在 HTML 工作台里画出下面五样，中英文各一套参考图，作为待确认候选，用户在「确认」页看过后确认：
1. **三滚轮开局台**（改 `ui.screen.reels`）：
   - 地图 → 收件人头像（`avatar.<id>`）→ 货物（`cargo.<id>`）依次停，标出稀有度；
   - 有重转按钮和剩余次数；
   - 地图轮显示地图的短名（石牢、地府）和一个小图标；
   - 不要再画 v1 的双滚轮。
2. **零食**：
   - 驿站货架加零食（改 `ui.screen.shop`）：10 金币，库存 3；
   - 包装按地图换：石牢小鱼饼干、地府桂花糕；海女村的零食如果 DSN-01 已合并，按它的设计画，没合并就先不画，写进交付；
   - HUD 上显示零食数（改 `ui.screen.delivery_hud`）。
3. **提示动物的气泡**（新建 `ui.screen.hint_animal`）：
   - 主动物头顶冒出提示的一句话，画法同对话气泡；
   - 人走近时画方向箭头；
   - 喂飞的动物时显示"喂零食要找猫 / 狗"。
4. **看全图**（新建 `ui.screen.observe`）：
   - 多屏房间缩小一半显示，2×2 正好 320 × 160；
   - 标出人、出口、怪物和提示动物，写"Tab 返回"；
   - 看全图时游戏暂停。
5. **多屏小地图**（放在 `ui.screen.delivery_hud` 里）：
   - 大小不一的房间（1×1 到 2×2）画在地图网格上；
   - 标出走过的房间、当前房间、收件人方向和驿站。

界面里画到的房间一律用 **v2 房间**（`content/rooms/dungeon/dungeon2_*`、`content/rooms/diyu/*`），不再用 v1 的房间。

## 模板

```markdown
# <编号> <一句话标题>

状态：待做 / 进行中 / 待审核 / 通过 / 退回（原因）
设计依据：<设计文档与章节>

## 目标
做完以后能看到、能验证的结果，一两句话。

## 要读的文件
- ...

## 要产出或修改的文件
- ...

## 不能碰的文件
- AGENTS.md 2a 的冻结区（除非这里明确写了允许改哪个文件）
- ...

## 验收标准
- 命令：`...` → 预期：...
- 画面 / 行为：...

## 交付（制作方填写）
- 改了哪些文件、跑了哪些命令和结果、没做完或有疑问的地方。
```

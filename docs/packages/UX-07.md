## 验收（运行什么 → 看到什么）
- M02 把箱子推到竖井下方 → 立刻出现"箱子卡住了……按 Z 退一步，或按 R 重开。"，撤销图标发亮；按 Z → 提醒消失，并说一次"按住 Z 可以一直往回退。"
- M06 站着不动 45 秒 → 撤销和灯泡亮一下；新存档第一次还会说"想不出来？按 H，我来想想办法。"，以后不再说。
- Mac 上 M04 按 H 三次 → 第三层显示 ⌘ + → 的键帽。
- 选关 M05 写"把门打开，走到旗那里。"；过 M05 → 过关画面有"你发现了"和原来那句。

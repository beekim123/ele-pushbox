# UI-07 配送 v2 的界面（三滚轮、提示气泡、观察模式、小地图、零食）

状态：界面线 · 待做（在 `ui/redo-html` 改版后的新样式上做；新界面美术是候选，用户确认后才进游戏）
设计依据：[delivery-puzzle-rules.md](../design/delivery-puzzle-rules.md) 第 4–6 节；[mode-delivery.md](../design/mode-delivery.md) 第 3 节；[art-direction.md](../design/art-direction.md) 第 7 节

## 目标
在 HTML 工作台里画出配送 v2 要用的界面（中、英文各一套参考图）：
1. **三滚轮开局台**：地图 → 收件人头像（`avatar.<id>`）→ 货物（`cargo.<id>`）依次停，标出稀有度；重转按钮和剩余次数。v1 已确认的双滚轮台保留给 v1，不改。
2. **提示**：主动物头顶的提示气泡（同对话气泡的画法）、走近时的方向箭头、HUD 上的零食数（`item.snack` × n）。
3. **观察模式**（Tab 看全图）：多屏房间缩小一半，标出人、出口、怪物和提示动物，写"Tab 返回"；定下看全图时是否暂停（建议暂停）。
4. **多屏小地图**：大小不一（1×1–2×2）的房间画在地图网格上，标出走过的、当前的房间，收件人方向和驿站。
5. **驿站货架加零食**（10 金币，库存 3），石牢小鱼饼干、地府桂花糕两种包装。

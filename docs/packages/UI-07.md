## 目标
UI-05 只画了 S1 晶石琉璃 · 素版的固定界面。这一包给 S2 漂浮符文、S3 祥云玉简、S4 梦泡糖霜各画一套同样的固定界面组件（面板、按钮两态、标题条、光标、气泡、HUD 底板等，界面布局不变），并在设置里加「界面风格」：四个选项，默认晶石琉璃；只换固定界面，大厅仍按章节换皮肤；商店和抽模式转盘固定不换。

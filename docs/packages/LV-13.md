1. 先导入：`node tools/content.mjs build && node game/tools/import_resources.mjs import`
2. 把这几处 `placeholder(...)` 换成按机关状态取精灵（例如灯照木板亮 / 暗、跷跷板左低 / 平 / 右低、矿车静止 / 滑行）。只用 `current_is_approved` 为 true 的资产；某项没确认就保留占位，写进交付。
3. `_level_has_placeholder` 里去掉已经有美术的机关类型。
4. 加测试：这 11 关开局时，画面里没有占位方块（可以检查 `placeholder` 的调用次数，不用逐像素比）。

## 目标
按用户选定的风格，做出**一整套**游戏界面。做完后用户在工作台「确认」页一次看完、确认：
1. **固定界面全部换成通用风格**，布局沿用现在 15 个界面的布局（选定的风格需要时可以小调）：
   - 选章、选关、设置；
   - 暂停、提示、规则卡、对话、过关；
   - 配送：开局台、商店、配送 HUD、配送暂停、结算、失败、放弃确认框。
2. **配送 v2 的界面**：
   - 开局台改成**三滚轮**：地图 → 收件人 → 货物，可以重转；
   - 商店货架加**零食**：10 金币、库存 3；包装按地图换，石牢小鱼饼干、地府桂花糕，海女村按 DSN-01 的设计，没合并就先不画；
   - 配送 HUD 加零食数和**多屏小地图**：房间 1×1 到 2×2，标出走过的、当前的、收件人方向、驿站；
   - 新建「提示动物气泡」`ui.screen.hint_animal`：主动物头顶的提示、走近时的方向箭头、喂飞的动物时的"喂零食要找猫 / 狗"；
   - 新建「看全图」`ui.screen.observe`：多屏房间缩小一半，标出人、出口、怪物、提示动物，写"Tab 返回"，看全图时暂停。
   - 界面里画到的房间一律用 v2 房间（`dungeon2_*`、`diyu/*`），不用 v1 的。
3. **通用大厅**：
   - 用在还没有自己皮肤的地图上（现在是地府、海女村）；
   - 原来按章节换的 6 套大厅皮肤保留不变。
4. 关卡 HUD（`scene.js` 的 `drawHud`）**不在这一包**：它是冻结的绘制文件。如果选定的风格要求 HUD 也换，在交付里写明，由 Claude 另开包。

| 问题 | 决定 |
|---|---|
| 1 挖和倒沙怎么按 | 先做 A：保留"按住 Shift / Ctrl + 方向"，Mac 上一律显示并教 ⌘。B（不用按住的字母键，先按 X / C 再按方向）和画面按键提示一起做。D（改键页面）往后放 |

| 6 按键提示什么时候永远消失 | B：做对一次就消失；之后卡在需要这个动作的地方太久，或隔了很久再玩，再出现一次 |
| 7 手柄 | B：现在先搭好"提示按设备显示"的结构（先只有键盘），手柄键位和图标以后补 |
| 8 鼠标 | A：保持左键挖、右键倒沙，悬停时显示真正会发生的动作 |

## 要产出
1. **新设计文档 `docs/design/onboarding.md`**（中文，用户能看懂）：
   1. **总则**：第一次需要时才教；做对一次就收起；不剧透；不挡关键格子；所有提示按设备显示（键盘 / 以后的手柄），Mac 显示 ⌘。
   2. **按键提示**（报告第 1、2、3、13 条）：
      - 画在画面哪里、用哪个已确认的键帽图（`ui.keycap` 等）；
      - 什么时候出现、做对后怎么消失、什么情况下再出现（决定 6 的"太久"和"隔了很久"写成具体数值）；
      - 顶栏撤销、重开、提示图标旁一直标着 Z、R、H；
      - 不用按住的备选键（先按 X / C 再按方向）的完整规则：按了以后怎么显示"等方向"、按错或超时怎么取消、和炸药 B 的关系。
   3. **目标说明**（第 5、6 条）：开局一句主角心里话（M01 槽和灯、M04 旗）；目标槽发光、箱子进槽时光飞向目标灯；新机关第一次出现时和右上角的符号一起闪。写清时长、颜色（用调色板代码）、能不能跳过。
   4. **卡住与死局提醒**（第 4、7 条，决定 2、5）：
      - "卡住"的判断标准写成数值（例如连续被挡几次、多少秒没进展）；

## 提示词正文

你之前按 v0.2 设计做出了 `pushbox-demo/`（推箱子：沙与水）。用户试玩后的结论是：**操作过于复杂，界面元素太多，像调试工具。** 设计已经改成 v0.3，附件 `demo-template.md`（下称“模板”）。**规则和关卡没有变**（模板第 3、6 章，你上次已经做对，D1–D5 的数值也对得上）；变的是操作、界面、画面和引导。你的任务是**在现有工程上改**。

### 1. 这次最重要的是什么

按优先级：

1. **新玩家一看就会**。模板第 2 章（玩家体验）是这次的头号规格：第一分钟、界面元素清单、操作、关内引导、反馈。界面元素清单之外的东西一律不许出现在画面上。
2. **画面**。按 `ui-art-direction.md` 做：320×180 基准、整数放大、ENDESGA 32 调色板、缝合像素字体 12px、自定义地形着色器。成品要比 `mockups/pushbox-*.png` 好，不能比它差。
3. 规则层不动：`board.gd`、`session.gd`、`level_loader.gd` 保留。你上次记录的 C01、C02 用户已经裁决“以模板为准”，参考实现也已改成与模板一致，D1–D5 结果不变。
4. 测试够用就行。每个里程碑交 **4 张 1920×1080 截图**（D1 开局、D2 悬停挖沙、D5 拖炸药、Esc 菜单），加一段不超过 15 行的说明。

### 2. 操作改成这样（模板 2.3）

| 要做的事 | 怎么做 |
|---|---|
| 走、推、登一格、爬梯 | 方向键或 WASD（不变） |
| 挖沙 | 鼠标左键点人物左、右、下方相邻的沙格 |
| 倒沙 | 鼠标右键点人物左、右相邻的空格或水格 |
| 看结果 | 指针停在能挖、能倒的格上就显示预演；点下去直接执行，**没有第二次确认** |
| 炸药 | 从右上角把炸药图标拖到相邻格，拖到格上显示预演，松手就炸，拖回去取消 |
| 拉杆 | 站在拉杆上按 ↑，或者点拉杆 |
| 撤销 / 重开 | Z / R，不弹确认 |
| 菜单 | Esc：继续、提示、重开、选关、设置、退出 |

去掉：工具模式（0/1/2/3）、“同方向再按一次确认”、`E` 互动、所有屏幕按钮（移动、工具、方向键、撤销、提示、作者解法、选关条、下一关）、回合数和 cell 数显示、类别边框（移到设置里，默认关）。作者解法只在开发版（F12）。

### 3. 文件怎么处理

按模板 7.1 的表：`preview.gd` 保留，改为悬停和拖炸药时触发、按目标缓存；`game.gd` 改输入；`ui/hud.gd` 重写；`ui/board_view.gd` 去掉默认边框、改预演样式、画引导；新增 `render/world.gdshader`、`ui/guide.gd`、`ui/pause_menu.gd`；关卡 JSON 加 `guides`（模板 5.4、2.4）。

### 4. 必须做对的地方

1. **画面尺度**：`EleWorld.cell_scale = 1`，1 cell = 1 像素，1 格 = 16 像素；视口 320×180、`stretch_mode = viewport`、`scale_mode = integer`。世界 320×192，最下面 12 行在画面外；`level_loader` 检查地图最多 20×11 格。
2. **悬停预演**：用你现有的预演世界和同一套结算代码；同一回合里同一个目标只算一次（缓存）；预演显示的结果必须和点下去的结果完全一样（模板 T6）。预演计算期间画面不卡顿：可以先只显示格子描边，结果出来再叠加。
3. **沙袋**显示成袋子图标（一个满袋 = 256 cell），不显示数字；炸药显示成图标，有几枚画几枚，而且可以拖。
4. **引导**：D1 墙上的 ↑、← → 键帽和“Z 撤销 · R 重开”；D2 浮在沙格上的鼠标图标（左键 / 右键）；D3 拉杆上的 ↑；D4 拖炸药的手。做对后马上消失，已经做过的直接跳过。
5. **着色器**按 `ui-art-direction.md` 第 5 节和模板 4.4：基岩砌块纹理和受光边、裂岩明显的裂纹、沙用颗粒色、水面高光；`crate`、`gate` 材料画成透明，由精灵表现（精灵做补间，模拟里的占位一步到位）。
6. **素材**：先用 `_work/mockups/art.py` 里的字符画精灵导出占位 PNG（人物、箱子、梯子、目标、拉杆、键帽、鼠标、手、炸药、沙袋），保证画面上没有纯色方块。正式素材由用户按他自己的 GPT 像素素材流程另行生成，届时替换文件即可，所以尺寸和锚点要严格按 `ui-art-direction.md` 第 7 节。
7. 过关后 1.5 秒自动进下一关（不弹完成面板）。
8. 不用任何 Godot 默认控件的原样外观；Esc 菜单是像素九宫格面板加几行字，选中的那行前面一个黄色小三角。

### 6. 遇到问题时

- 模板和附件互相矛盾、或者照做会明显不好玩：**停下来，写清楚矛盾和你的建议，问用户**，不要自己选。
- 不要改 SDK；不要改第 3、6 章的规则和关卡。
- 沿用你上次工程里的资源限制（单 worker、顺序跑测试等）。

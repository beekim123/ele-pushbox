## T8 实测

真实 macOS 窗口、OpenGL 4.1 Metal / Apple M3。最新完整运行采集 250 个结算 CPU 帧、8 次破坏性工具预演。结算统计为完整 `Game._physics_process` + 当前帧 SDK 上传 + 当前帧叠加绘制；上限每帧 4 SDK tick，开局动画每帧 1 tick。包含开局后续结算及快照任务的主线程轮询/HUD；同步关卡创建和 tick-0 地图绘制另列 load。预演包含快照文件 I/O、结算与差异生成。排除主动帧等待/vsync 和 GPU 光栅耗时，不能视为所有外部系统负载下的硬实时保证。

| D2 | 0.204 | 1.154 | 1.857 | 9.628 | 10.097 |

最初测到整图冷分类及同步开局 I/O 峰值，早期完整重跑也有超过 4 ms 的帧，失败日志已保留。最终优化为均匀行/类别缓存、只在变化时重绘，以及 SDK 已有 count_materials 提供材料计数；Board 不调用 SDK，ID-only 路径保持独立可测。1200 个计数对照全部一致，之后完整 10 脚本运行通过，报告采用此最新结果。

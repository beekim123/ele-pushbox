# 验证记录

本目录保留小体量的验证日志、数据和截图，包括历史失败与最终通过记录。它们用于说明 Demo 的技术基线；用户反馈的屏幕适配和人物越障问题仍待后续排查。

- `logs/`：早期 Demo 实现与验证记录。
- `v03/logs/`：v0.3 顺序测试记录与性能数据。
- `v03/m1/`、`m2/`、`m3/`：各阶段的实际渲染截图和说明。
- `v03/red/`、`scheduling/`：历史失败、调度对照和后续通过证据。
- `2026-10-14-goals/`：按用户指示中止的局部试玩记录，不作为 Bug 验证通过证据。
- `2026-10-14-repository/`：本次仓库整理后，从待提交文件导出的独立副本运行的验证结果。

ZIP、快照、SDK 构建环境报告、编译日志和临时路径文件不进入版本控制。历史 ZIP 清单中的哈希描述当时的交付包，不代表当前仓库文件的哈希；生成新包时由打包工具重新记录。
